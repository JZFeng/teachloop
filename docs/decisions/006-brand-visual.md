# 决策 006 — 前端视觉换成 TeachLoop 新 logo 的品牌层

日期：2026-10-22　状态：已实现，待用户验收视觉　相关：`specs/006-brand-visual/`、
`docs/brand/`（两张源图与用途，唯一存放处）、
`docs/research/2026-10-22-brand-visual.md`、`docs/mock/brand-2026-10-22/`、
`docs/reports/brand-app-2026-10-22/`

## 问题

产品定名 TeachLoop，用户给了一版新 logo（深海军蓝字标 + 亮蓝/青绿循环 + 铅笔黄 + 玫红柱，
四个功能位 Create / Assess / Practice / Insights，tagline「Better Practice. More Insights.」），
要求「前端 UI 往这上面靠一靠，改所有页面」。

2026-10-21 的 003 已经把界面定成「教育行业稳重」：主色 `#1D5FBF`、圆角 6/8、系统字体、
亮暗两套、组件层与 `check-ui` / `contrast.py` 守卫。这次不是推翻它，是**在结构不动的前提下换品牌皮肤**：
密度、实边框、无渐变、无 emoji、两套主题、令牌唯一真源全部保留。

真正的约束来自 logo 本身。取样后实测：

| logo 元素 | 值 | 白底对比度 | 结论 |
| :--- | :--- | ---: | :--- |
| 字标深海军蓝 | `#0E3676` | 11.62:1 | 可做文字 |
| 循环亮蓝 | `#1F8DFD` | 3.34:1 | 只能做图形 |
| 铅笔青绿 | `#20B998` | 2.48:1 | 只能做装饰 |
| 铅笔黄 | `#FEBF41` | 1.65:1 | 只能配深色内容 |
| Insights 玫红 | `#A63960` | 6.22:1 | 可做文字 |

也就是说：**logo 的亮色一个都不能当主按钮底或正文**。同时产品本身有判分三态（对 / 部分对 / 错），
与新 logo 的四个功能色会撞（青↔绿、黄↔琥珀、玫红↔红）。这两件事必须在令牌层解决，不能靠页面自觉。

## 决策

**新增品牌层，分三个命名空间；亮色只做填充，文字用深一档 ink；功能色与判分色不互相 alias；
结构、密度、组件入口、两套主题、守卫机制全部沿用 003。**

| 项 | 决定 |
| :--- | :--- |
| 主操作 | `#1A63E0`（白字 5.38:1）；暗色 `#2A6FD6`（4.84:1）。不用 logo 亮蓝 |
| 品牌原色 | `BRAND`：navy `#0E3676` / azure `#1F8DFD` / teal `#20B998` / yellow `#FEBF41` / rose `#A63960`；主题无关，只做填充 |
| 功能位 | `FEATURE_*`：Create 蓝 / Assess 青 / Practice 玫红 / Insights 靛蓝（2026-10-23 调整，见下）；Practice 未上线，只占位 |
| 判分三态 | `STATUS_*`：pass / partial / fail，与功能位分开命名；标签始终带文字 |
| 暗底 | `#0A1120` / 面板 `#101A2C`；暗色检查从令牌读，不再写死 `#141414` |
| 链接/次级蓝字 | 新增 `--accent-text`：亮 `#1A63E0`、暗 `#7DB1FF`；`--accent` 只留按钮底/焦点环/边框 |
| 圆角 | 卡片 12 / 控件 8 / 小件 6；控件高 32、正文 14/1.65、字号六档不变 |
| 字标 | 不引 webfont：亮色大字位用裁切位图，暗色与侧栏用 `Brand` 的 mark + 文本字标 |
| 品牌资产 | `scripts/brand/build-assets.py`：源图 sha256 固定、四角洪水去背 + 边缘去白、9 个资产 + manifest |
| 页头 | `PageHeader` 按路由前缀出 eyebrow（CREATE/ASSESS/INSIGHTS/中性），页面不手写颜色 |
| 落地范围 | 全站 24 条路由继承令牌；登录页重排；导航加功能色胶囊；`/ui-kit` 加品牌色板；30 张真页面截图 |
| 守卫 | `contrast.py` 16 → 40 组；`check-ui` 与 `check-i18n` 基线不上升 |

> **导航着色口径（2026-10-22 明确；已被 2026-10-23 修订取代，保留原文作历史）**：功能色只标注三个**已上线**功能位——作业·试卷 `create`、
> 批改·复核 `assess`、报表·我的反馈 `insights`；首页、班级、资料、通知、管理员 AI 是**中性导航**，
> 刻意不配 `tone`，图标用 `--muted-2`（`Shell.tsx` 的 `NavItem`、`PageHeader.tsx` 的路由映射、
> AC-31.2 三处一致）。Practice 紫色只占位（模块未上线），不借给导航项。
> 理由：功能色是「模块身份」编码，不是装饰；给中性项硬配颜色会造出第五条语义，或提前消费未上线的
> Practice，同时让「功能色只出现在胶囊/eyebrow/功能位/图表」的 AC-31.4 边界变模糊。

### 2026-10-23 修订：首页 / 班级上色，Insights 改靛蓝

用户看过样张后提了两条：首页、班级「太素」；报表的玫红在暗色下像「出错」，要换一个更表意的颜色。
两条都推翻上面的 2026-10-22 口径，所以在这里连同理由一起落盘。

| 项 | 2026-10-22 | 2026-10-23 |
| :--- | :--- | :--- |
| 首页 | 中性灰图标 | 空间海军蓝 `#0E3676` / `#E7EDF7`（暗 `#8FB4FF` / `#152640`） |
| 班级 | 中性灰图标 | 空间淡紫 `#5B3AC4` / `#EAE0FD`（暗 `#A78BFA` / `#1E1A3A`） |
| Insights（报表/反馈） | 玫红 `#A63960` / `#FDE2E7` | 靛蓝 `#3F51B5` / `#EAECFB`（暗 `#A5B4FC` / `#1E2545`） |
| Practice（未上线） | 紫 `#5B3AC4` / `#EAE0FD` | 玫红 `#A63960` / `#FDE2E7`（接收 Insights 退下来的色） |
| 命名空间 | FEATURE / STATUS / BRAND | 新增 SPACE（`--space-home`、`--space-classes`），不借 FEATURE |
| 选中态 | 统一 `--accent-weak` + `--accent-text` | 不变（不跟各自色走） |
| 守卫 | 40 组 | 44 组（新增首页/班级 ink×tint 亮暗 4 组） |

理由：

- **首页与班级是空间，不是功能位**。首页是聚合页、班级是对象列表，它们没有「Create / Assess / Insights」那样的流程身份；
  给它们颜色是为了扫读，不是为了多造两个模块，所以单独开 `SPACE_*`，并且**不进口 eyebrow**。
- **玫红在暗色下就是错误色**。`#E58BB0` 压在 `#33141E` 上，与判分「错」的红同族；用户第一眼读成报错。
  靛蓝在亮暗两套都与状态色无冲突，且与批改青、创建蓝各差 20° 以上色相。
- **Why not 琥珀**：琥珀已经是「部分对」，在导航里再出现一次，两条命名空间就借色了。
- **Why not 石板**：`#44546F` 只比现在的 `--muted-2` 深一档，样张里几乎看不出变化，解决不了「太素」。
- **Why not 品红 / 深青**：品红仍是红系，深青紧贴批改/复核的青，相邻两行会糊成一片。
- **Practice 为什么跟着换**：班级要用淡紫，而淡紫原本是 Practice 的占位；两个令牌同值比换色更糟。
  Practice 未上线，此刻换色成本最低；空出来的玫红正好有出处（它就是 Insights 原来的色）。

选型证据：`docs/mock/nav-color-2026-10-23/`（六种做法并排，亮/暗/选中态）、
`docs/mock/insights-color-2026-10-23/`（报表七种颜色并排）、`docs/research/2026-10-23-nav-color-codes.md`。
真页面证据：`docs/reports/nav-color-2026-10-23/`（36 张，教师 + 学生 + 登录页，含 `home-{light,dark}.png`、
`classes-{light,dark}.png`）。

### 用户拍板的三件事

1. 交付顺序：先出可点样张、确认后再改真前端（样张见 `docs/mock/brand-2026-10-22/`，用户「很满意」后开整）。
2. logo 源：没有矢量文件，接受从 PNG 裁切；2026-10-22 又更新了一版（4 个功能位、新 tagline），以新图为准。
3. 范围：直接改所有页面，不等逐屏排期。

## 为什么

- **亮色不进文字层**：WCAG 1.4.3 只豁免 logo/字标本身，不豁免界面正文；3.34 / 2.48 / 1.65 都过不了 4.5。
  亮色留在 logo、插画、粉彩底与图表里，界面文字用同族深色，两件事不冲突。
- **功能色与判分色分开**：判分是「对错」，模块是「身份」，两者混用会让教师把青色当成「对」。
  分成两个命名空间后，读代码就能判断一个颜色能不能表达判分。
- **暗色字标用文本**：深海军蓝字标在暗底只有 2.14:1；硬做反色位图会发毛，文本字标任意尺寸都清晰。
- **页头走路由映射**：新增页面不会「忘了加品牌层」，也不会同一个模块两种叫法；改一处全站生效。

## 不采纳

- 不引 webfont（中文 webfont 1–5 MB，与自托管/离线冲突）。
- 不把 logo 五个/四个功能位直接做成五个导航项：Practice / Words 没上线，画出来是空承诺；新 logo 已去掉 Words。
- 不做 9 套主题、不做色盲/高对比变体：用「状态带文字 + 图标」从结构上替代。
- 不做 codemod / 逐屏重写：令牌 + 页头 + 壳层统一，其余屏继承。
- 不改 `Tag` 的 tone 语义（仍是 blue/green/amber/red/gray），判分三态靠令牌值与文案区分。

## 后果

- 003 的调色板与圆角被本决策取代；003 的结构性规则与守卫仍生效，其 spec 顶部已标注。
- 宪法第十五条补了品牌层三条（命名空间、亮色只填充、资产与守卫）。
- 40 组对比度成为新的下限；以后加功能色/状态色必须同步进 `contrast.py`，否则脚本会漏检。
- 已知未验证：考试作答 live 页（要真实开始作答）、管理员 AI 设置（要 ADMIN 角色）、反馈详情页、`/setup`、跨浏览器；
  详见 `specs/006-brand-visual/spec.md` 6.2。
