# 决策 007 — 写作题按题项存 rubric、按篇判分

日期：2026-10-22　状态：已拍板、实现中　相关：T360–T367、D-23~D-27、
`docs/research/2026-10-22-essay-rubric.md`、spec `AC-4.21~4.23` / `AC-27.17~27.19` /
`FR-082~084`

## 问题

用户拿两份真实卷子试导入：

1. `整个考卷含写作.md`：第 191 行报
   `无法解析的答案行「15. 应用文写作示范范文：」（支持 1. A / 1A / 1 A / 1-5 ABCDA / 1 A 2 B 3 C）`。
2. `paper and answer.md`：能导入，但**第四部分写作 0 题、只有 120 分**（卷面写 150），
   向导第 4 步只有一个 rubric 编辑框。

三件事叠在一起：

- `PaperTextParser` 对标题含「写作 / 作文 / 应用文 / 口语」的部分整块跳过（旧 AC-4.15 / D-12），
  写作题根本没有题项。
- rubric 是**试卷级唯一一份**（`papers.rubric_markdown` → `offerings.rubric_markdown` →
  `WorkItem.rubricMarkdown`），两道写作题只能共用一份，AI 也只能一次判全部。
- 判分取正文只读 `submissions.content_text`，而考试作文的正文在 `answers[]` 里，
  等于拿空文本判分。

## 决策

| 项 | 决定 |
| :--- | :--- |
| 写作题建不建题项 | **建**。标题命中写作/口语的部分，有「第X节」按节一题，否则按带题号的写作任务行一题；节内编号清单是内容要点，不拆题（D-23） |
| rubric 挂哪一级 | **题项级** `objective_items.rubric_markdown`（只对 ESSAY）；为空回退试卷级 rubric；题项 rubric 的分值只约束本题，不进试卷总分（D-24） |
| 参考范文 | 题项级 `reference_markdown`，**只给教师看**，不进 AI prompt、不进学生端；答案区按写作题号绑定，没有题号不猜归属（D-25） |
| 判分粒度 | **逐篇**：每道有作答的 ESSAY 一次模型调用，逐项结果带 `itemNumber` 合并；空白作文 0 分不调用（D-26） |
| 作文正文来源 | 优先 `answers[]` 中该题号；全卷仅 1 道 ESSAY 时才回退 `content_text`（独立作业路径） |
| 分值写法 | 题项/小节/写作任务/rubric 评分项统一 `分 / points / pts`，括号全角半角均可；`每小题 X 分` ≡ `X points each`（D-27） |

## 为什么不按「一次调用多篇」

现有 `SubjectiveGradeRequest` 是**单文本 + 单 rubric** 语义（隐私边界还刻意不含 `answers` /
`answerKey`）。要做一次多篇，就得改成结构化分包输出：模型要按题号分桶返回，串题与漏项的风险由
提示词兜，校验器也要跟着改。逐篇调用的代价只是 k 次调用（一份卷通常 1–2 篇），换来：

- 每篇的 rubric、字数区间、题面互不污染；
- 单篇失败能定位（哪道题的输出不合规）；
- 继续复用现有的输出契约与 `GradeOutputValidator`，不新增一套校验。

## 后果

- 2 篇作文的判分时延约 2 倍、token 少量增加（system prompt 多一行「本题」）；串行，暂不并发。
- 导入一个「写作 + 口语」的卷子会多出 2 道 `ESSAY` 题项，学生端按写作题渲染（`wordLimitFor`
  对 15 分给 80 词，符合卷面要求）。
- 旧卷子若已用 `section_criteria` 表示写作分值，导入时会提示重复、发布端拦截，避免总分翻倍。
- 历史快照 / 历史 `ai_criteria` 没有新字段 → 空值回退，不迁移数据。

## 验收

- `整个考卷含写作.md`：0 报错，14 客观 + 15/16 两道写作题，两篇范文各归其题。
- `paper and answer.md`：75 客观 + 76/77 两道写作题，总分 150，缺答案 0。
- 向导第 4 步逐题 rubric 可编辑、回填；复核页 AI 评分项按题分组。
- 两篇不同 rubric 判分 → 2 次调用，第 15 题的 rubric 不出现第 16 题的 prompt。
