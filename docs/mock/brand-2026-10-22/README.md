# TeachLoop 视觉样张 v1（2026-10-22）

这是**需求评审用的可点样张**，不是交付代码。真前端要从 `web/src/ui/tokens.ts` 与
`web/src/styles/tokens.css` 重写一遍，不复用这里的 HTML/CSS。

## 怎么打开

双击 `index.html` 即可，不需要起服务、不需要联网、没有构建步骤。

- 顶部深色条是**预览控制**，不是产品 UI：
  - **屏幕**：登录 / 试卷库 / 新建作业 / 品牌令牌
  - **亮色 / 暗色**：同一套令牌换值
  - **品牌 / 克制**：色彩强度两档，用来判断「会不会太花」
  - **状态**：当前屏的空态 / 出错 / 加载 / 合计不一致
- 也可以直接用 URL 参数固定一张图（截图脚本就是这么做的）：
  `index.html?screen=papers&theme=dark&intensity=brand&state=empty&chrome=0`
  （`chrome=0` 隐藏预览控制条）

## 四屏分别看什么

| 屏 | 看什么 | 可选状态 |
| :--- | :--- | :--- |
| 登录 | 大字位整标、tagline、三条卖点、四个功能胶囊；亮色用位图整标，暗色用「图形标 + 文本字标」 | 默认 / 错误 / 加载 |
| 试卷库 | 侧栏品牌区与五色导航胶囊、页头 eyebrow、表格密度、状态标签、操作链接 | 有数据 / 空 / 出错 / 加载 |
| 新建作业 | 表单密度、Markdown 编辑器外观、评分标准与「AI 将看到」合计校验、班级胶囊 | 默认 / 合计不一致（总分改 15） |
| 品牌令牌 | 色板与实测对比度、logo 四种底色、字阶、圆角、组件状态、使用规则 | — |

## 数据来源（别把它当真实数据）

- 文案：`web/src/locales/zh-CN.json`（登录三条卖点、表单标签、提示语）。
- 试卷/班级：`DemoSeedRunner`（演示试卷 30 分 / 90 分钟 / 3 题，演示班 30 人）与已有 QA 截图
  （期中模拟卷 14 分、高一（3）班）。

  **是为了让列表有层次补的演示值**；真前端落地时一律从 API 取，不抄样张。
- 样张里没有任何生产环境数据。

## 设计事实（数字都算过）

- 主操作 `#1A63E0`（白字 5.38:1）。logo 亮蓝 `#1F8DFD` 对白只有 3.34:1，**不能当按钮底**；
  亮蓝、青绿、黄只做图形与粉彩底。
- 功能色与判分状态色分开：功能色进导航胶囊/eyebrow，状态色进带文字的状态标签。
- 亮暗各 20 组、合计 40 组对比度，真前端由 `scripts/ui/contrast.py` 复算。
- 圆角 6（小件）/ 8（控件）/ 12（卡片）；控件高 32、正文 14px 不变。
- 不引 webfont：位图只用于大字位，暗色用文本字标。
