Logo 用法

位图裁切自你给的 1254×1254 原图；去背后在四种底色上都不带白边。图形标用于侧栏与小尺寸，整标只用于登录页大字位。

#FFFFFF
#F6F8FC
#0E2340
#0A1120
  • 留白：图形标四周至少留 0.5 倍高度，不贴边、不加投影。
  • 尺寸：侧栏 34px 宽、favicon 32px、登录页整标 344px；小于 24px 时只保留图形标。
  • 字标：亮色大字位用裁切位图；暗色与小尺寸用文本字标（Teach 正文色 / L 亮蓝 / oop 青绿）。
  • 不改色：图形标里的蓝、青、黄是品牌资产，不随主题染色。
  • 不拉伸：只等比缩放；不裁掉火花，不重排笑脸。
  • 不压字：logo 不叠在正文或截图上，背景只用纯色或最浅粉彩。

使用规则

这几条会写进宪法第十五条，并由对比度脚本与新规则守住。

该这样用

  • 亮色只做填充与图形；文字用压深一档的同族色。
  • 一个视图里最多两种功能色；当前模块最多一种。
  • 状态标签带文字；图表带直接标注，保证色盲可读。
  • 暗色主按钮用 #2A6FD6（白字 4.84:1），不要为了「更亮」升到 3.x。

不要这样用

  • 不要把 #1F8DFD / #20B998 / #FEBF41 当 14px 文字或主按钮底。
  • 不要把功能色（青）当成功色（绿）用，两者语义不同。
  • 不要给主按钮加渐变或彩色投影，那是 2021 模板味。
  • 不要在中文上加 uppercase 或 letter-spacing 装饰。
