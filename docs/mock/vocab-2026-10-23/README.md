# 背单词原型 · 2026-10-23（第三版）

对应规格：`specs/004-vocab/spec.md`（US-46–61）、计划 `specs/004-vocab/plan.md`
单文件、无依赖、无构建：**双击 `index.html` 就能点**。


## 第十版（导入的清洗与拼写校验）

导入预览现在有三态校验，并且**从不自动改词**：

| 状态 | 界面 | 操作 |
| :--- | :--- | :--- |
| ✅ 词表命中 | 绿色「命中」 | — |
| ⚠️ 疑似拼错 | 黄色「疑似拼错」+ 候选（编辑距离 ≤2） | 逐条「用建议 / 忽略」，或顶部「全部采用建议」（二次确认） |
| ❔ 词表外 | 灰色「词表外」 | 不阻拦导入；专有名词/缩写/生僻词照常入库 |

格式清洗（序号、全角标点、引号）自动完成，但每类改动都在预览里逐条列出。

## 第九版（收藏 / 暂停 / 删除 分工）

| 动作 | 在哪 | 说明 |
| :--- | :--- | :--- |
| ☆ 收藏 | 词库行 + 详情页 | 纯标记；筛选弹窗新增「已收藏」条件 |
| 暂停 / 恢复 | 词库行 + 详情页 | 不再排期，词还在库、可搜索；恢复后回到新词 |
| 删除 | **只在词库页**（行内 + 批量） | 软删除：列表/搜索/队列/统计都看不见，历史保留 |

原文的「移出复习 / 重新加入生词本」已统一改名为「暂停复习 / 恢复」；详情页不再有删除入口。

## 怎么走完主流程

1. 打开后默认 **学生 · 我的词库**，顶部是「王砚秋老师发来 Unit 5 生词」横幅。
2. 点任一张统计卡 → 列表被过滤；再点一次取消。
3. 勾几个词 → 批量标记「已熟悉」。
4. 点单词 → **单词详情**（同一份模板 + 不同 JSON）。
5. 回词库，点「▶ 复习这些词」→ **自由复习**：空格翻面、1–4 评分、`S` 移出复习、随时「结束复习」。
6. 顶栏切 **教师** → 词集 / 发词。
