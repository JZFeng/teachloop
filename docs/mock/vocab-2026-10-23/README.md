# 背单词原型 · 2026-10-23（第一版，待 review）

对应规格：`specs/004-vocab/spec.md`（US-46–57）
单文件、无依赖、无构建：**双击 `index.html` 就能点**。

## 怎么走完主流程

1. 打开后默认是**学生 · 我的词库**，顶部有一条「王砚秋老师发来 Unit 5 生词」的横幅 —— 这就是主用例的入口。
2. 点「查看并加入」→ 词进词库（原型里只用横幅与提示示意，未做领取抽屉）。
3. 左侧切到 **今日复习** → 点卡片或按空格翻面 → 按数字键 1–4 或点四个按钮评分。
4. 顶栏切到 **教师** → 左侧出现 **词集 / 发词**。
5. **词集**：左列选词集，右列看词条顺序；右上角「发给班级」直接跳到发词页。
6. **发词**：选班（灰掉的是非本人班级）、设截止、写说明 → 发送 → 出现「已发送」回执。

## 顶栏三个开关

| 开关 | 作用 |
| :--- | :--- |
| **有数据 / 空 / 出错 / 加载** | 每屏都能切四种状态；空态与出错态是这次特意画出来的 |
| **学生 / 教师** | 切换角色与导航（学生 2 项、教师 2 项，其余为灰显的既有入口占位） |
| **暗色 / 亮色** | 令牌两套值来自 `web/src/styles/tokens.css` |

深链（方便评审时直接打开某一屏）：`index.html#review`、`#wordset`、`#assign`、
`#review?flip=1`、`#review?theme=dark&flip=1`、`#library?ds=empty`、`#library?ds=error`。

## 画的时候发现、需要回写规格的 5 处

画屏比读规格更容易发现缺口，下面这些已经补进 `spec.md` §11：

1. **空词库时，「班级发来的生词」横幅必须仍然显示**。否则新用户第一眼看到的是空态，而唯一能让词库有内容的入口被藏起来了。
2. **评分按钮在翻面之前应当禁用**（原型里未翻面时四个按钮降到 45% 不透明）。规格原文只写了「显示各自的下次间隔」。
3. **「今日复习」右侧那三个数需要口径**：新词、到期复习、今天已复习 —— 分别对应「今天新进队列的张数」「今天到期且已到时间的张数」「今天已评分的次数」。
4. **非本人班级在发词页怎么呈现**：原型是「灰显 + 标注非本人班级」，不可点。规格原文只写了后端返回 404，前端要不要显示是空白。
5. **词集里「移除」的语义**：原型按「只把词移出词集」处理（不删词条、不影响学生已领的词），需要一条验收标准钉住。
