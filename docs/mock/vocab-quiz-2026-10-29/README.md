# 复习小测原型（2026-10-29）

对应决策：`US-87`（拟，落在 `specs/004-vocab/spec.md`）；变更清单见对话记录。
单文件、无依赖、无构建：**双击 `index.html` 就能点**。

## 这一版在回答什么

1. 今日复习结束 / 自由复习结束后，**入口长在哪里**（完成卡 + 小结页主按钮）。
2. **整卷**而不是一屏一题：复习场景 60% 以上的词是过的，逐题翻页比答题本身还慢；
   整卷也顺带解决了「不给即时对错」的理由——先看到第 3 题解析会泄露第 12 题答案。
3. 交卷后**统一解析**，错题带进下一次 `review-back`（只读标记，不改排期）。

## 屏与深链

| 屏 | 深链 | 重点看什么 |
| :--- | :--- | :--- |
| 今日复习 · 完成卡 | `#done` | 空态改完成态：20 个词 / 认识 15 / 不认识 5 + 主动作「来个小测 · 10 题」 |
| 自由复习 · 小结 | `#summary` | 主按钮「今日小测 · 20 题」与已有按钮的层级关系 |
| 整卷 | `#paper` | 一屏 10 题、选择/填空混排、底部固定条（已答计数 + 未答提醒 + 跳过 / 交卷） |
| 结果 | `#result` | 8/10 答对、逐题解析（原句 + 你的答案 + 正确答案 + 中文）、「复习错题 / 再来一轮 / 今日复习」 |
| review-back 标记 | `#back` | 「上次测验答错 · 10-28」这一行在卡片反面的位置与重量 |

## 已知取舍（不是漏做）

| 主题 | 现在的做法 | 为什么 |
| :--- | :--- | :--- |
| 干扰项 | 从同批词里取，**不保证同词性**（第 1 题 `glance` 在语法上可排除） | 确定性出题不调模型；同词性优先只是排序规则，词性不足时会降级。V1 接受「有时太好排除」 |
| 填空判分 | 同词族任意词形都算对（`struggle / struggled`） | 屈折不是词汇问题；正文原句用的是 `struggled` |
| 同一词两题 | 允许，但**必须隔 ≥5 题**（第 2 与第 7 题） | 相邻会互相提示；同一句不得重复 |
| 20 题在小屏 | 单页滚动 + 固定交卷条，不分页 | 分页会让「一次扫完」的效率优势消失；固定条保证随时能交 |
| 语音/听力 | 不做 | 不在本期边界 |

## 记录保留（回答「要不要只保存答完的」）

不能只保存答完的，因为：① 判分必须在服务端，题目与答案不能交给浏览器；②「点开小测但没交卷」的比例是 AB 的核心分母。

| 状态 | 保留 | 说明 |
| :--- | :--- | :--- |
| `IN_PROGRESS` | 7 天后清理 | 中途放下可续；放弃率可算 |
| `SUBMITTED` | 长期 | 10 行/天/人 ≈ 3650 行/年，量很小 |
| `ABANDONED`（可选） | 同 IN_PROGRESS | 显式「不做了」时置位，指标更干净 |

## 与 paper 的关系

**不用 paper。** ① paper 是 出题→发布锁→布置→快照→批改→复核 的考试链路，10 道自测走不动；② `scripts/check-deps.py:27` 只允许 `vocab` 依赖 shared/identity/classroom，模块边界上就 import 不到 paper；③ 自测不需要分卷、布置、教师复核。将来「老师布置词汇测验、进成绩报表」才走 paper。
