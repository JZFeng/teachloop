## 4. 未覆盖 / 偏离（照实写）

1. **「注册」路径用种子学生替代**：注册后要收激活邮件（`docs/process/e2e-playwright.md` §2.3 明确
   不能用于自动化），路径 1 从「加词」开始，其余步骤一致。注册→激活链路本身由
   `RegistrationFlowTest` 覆盖（后端集成测试）。
2. **今日复习仍是页内卡片，不跳 `/vocab/review/session/:id`**：AC-91.3 写「在复习页点开始后进入全屏会话」，
   但 004 的今日复习交互就是 `/vocab/review` 页内卡片（队列 + 预取 + 快捷键），改成会话会重写那条链路。
   本次做的是：**free-review（词单/词库发起）全屏无侧栏无 Tab**（`VocabFocusLayout`），
   今日复习保持原交互。这是与 AC-91.3 字面的偏差，需要产品确认后再决定是否改。
3. **AC-90.1 的「连续天数」没有实现**：今日页聚合接口的三段契约里没有 streak（学习记录卡是 spec §6 的
   第二期），Plan 也没给数据源；页头只显示 `班名`（有班）或「个人学习」（无班），不编数字。
4. **AC-90.2 的「页内展开」**：作业卡默认 3 条，「查看全部 N 条」在页内展开；后端返回全部待办（不截断），
   所以展开有内容可显示。
5. **邀请码成功提示在页面级**（不在卡内）：`inClass` 变 true 会让邀请码卡卸载，卡内提示看不见。
