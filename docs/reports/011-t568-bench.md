# T568 证据：背单词 / 今日页基准（011）

- 日期：2026-10-30
- 对应验收：`specs/011-self-study-mode/tasks.md` T568「开启 `pg_stat_statements`；`scripts/bench-vocab.py`
  造 5000 词 + 500 条日志，记录队列与词库页 P95；`/api/student/today` P95 < 50ms」
- 脚本：`scripts/bench-vocab.py`（本文件所有数字都由它产出，可复跑）

## 1. 环境（隔离，不动 dev / qa / prod）

| 项 | 值 |
|---|---|
| 数据库 | 临时容器 `teachloop-011-bench`（postgres:16-alpine，`:55440`，`shared_preload_libraries=pg_stat_statements`） |
| 后端 | 同一 jar（`feat/011-today` 构建），`:8021`，`SPRING_PROFILES_ACTIVE=dev`，AI/内容生成 = stub |
| 前端 | 未参与（只打 HTTP） |
| 数据 | 5000 词 + 500 条 `vocab_review_logs`（同一天内、分布在 500 分钟内） |
| 机器 | 本机 macOS（Apple Silicon），单进程、无并发 |

为什么另起容器：本机共享的 `teachloop-pg` 没有预加载 `pg_stat_statements`，改它的启动参数会重启
别人正在用的 dev 库。临时容器跑完即删，证据可复现且不影响任何人。

## 2. 结果（30 次顺序采样，先 3 次预热）

| 端点 | p50 | p95 | p99 | max |
|---|---|---|---|---|
| `GET /api/student/today` | 8.8 ms | **10.1 ms** | 10.2 ms | 10.2 ms |
| `GET /api/vocab/review/queue?limit=100` | 13.5 ms | 16.5 ms | 18.0 ms | 18.0 ms |
| `GET /api/vocab/words?page=1&size=50` | 10.5 ms | 12.5 ms | 13.6 ms | 13.6 ms |

灌数据耗时：5000 词 **2.7s**（10 批 × 500，`POST /api/vocab/words/paste`）；
500 条复习日志用 psql 直插（接口会写 SRS 排期，基准不该改学习状态）。

**结论：`/api/student/today` p95 = 10.1ms < 50ms → PASS。**

## 4. 复跑

```bash
docker run -d --name teachloop-011-bench \
  -e POSTGRES_USER=teachloop -e POSTGRES_PASSWORD=teachloop -e POSTGRES_DB=teachloop \
  -p 55440:5432 postgres:16-alpine -c shared_preload_libraries=pg_stat_statements

DB_URL=jdbc:postgresql://localhost:55440/teachloop DB_USER=teachloop DB_PASSWORD=teachloop \
  SPRING_PROFILES_ACTIVE=dev PORT=8021 TEACHLOOP_GRADING_ENGINE=stub VOCAB_GENERATION_ENGINE=stub \
  java -jar teachloop-app/target/teachloop-app-0.1.0-SNAPSHOT.jar &

python3 scripts/bench-vocab.py --base http://127.0.0.1:8021 \
  --db-container teachloop-011-bench --words 5000 --logs 500 --samples 30
```

## 5. 口径与限制（不掩盖）

1. **单用户、无并发**：这是「一个人打开今日页要多久」的数字，不是压测；并发下连接池与 CPU 竞争未测。
2. **stub 生成**：内容生成用替身引擎，测的是读取路径；真实 AI 生成的延迟不在今日页请求里（异步）。
3. **p95 用 30 个样本**：样本少，p99 只作参考，不作为承诺。
4. 数据是本机 dev 库的形态（5000 词全在一个人名下），生产量级（多租户、几十万词）未测。
