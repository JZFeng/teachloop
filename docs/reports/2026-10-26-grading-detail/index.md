# 批改详情页重做 + 列表工具栏标准件（T499–T502）验收报告 — 2026-10-26

**结论**：用户列出的 11 条问题 + 追加 3 条，全部落地。详情页现在：

- 「提交明细 / 成绩汇总」是**带下划线的真页签**，带计数与「未公布 · 预览」角标；
- 筛选条删了，换成与首页/词库同一套 `TableToolbar`（筛选 · N / 列 / 清空），筛选值写 URL；
- **0 人交卷时不再是一屏 0**：4 张统计卡与空表都消失，改成「还没有人交卷 + 应交/截止 + 按班分组的未交名单」，
  5 个动作全部禁用并各自写明原因；
- 两个「发布」并排说清：`已发布`（作业对学生可见）与 `成绩未公布/已公布`；
- 截止时间进了副标题。
- 汇总与发布的关系按你选的做：**不做硬门禁**，未公布时标「预览」并说明学生看不到分数，
  已公布时进入详情页自动落到汇总页签。

## 5. 未验证 / 已知缺口

- **「已公布后默认落汇总」未实测**：QA 环境 4 场作业都还是 `publishScores=false`，没有可验证的数据；
  逻辑由 `defaultTab()` 单测覆盖，页面跳转路径只做了代码层检查（`?tab=` 优先级已实现）。
- **「成绩已公布」标签形态未实测**：同上，没有已公布成绩的作业。
- **9 人以上的未交名单换行**：演示班 28 人一行排下来会占 2–3 行，未做折叠（现有形态可读，但不够紧凑）。
- **移动端/窄屏**：只到 1280 与 1024，手机未测。
- **催交（第 9 条）没做**：需要后端通知接口，属新功能。
- **`make test` 全量**：本次只跑前端（117/117）与四个守卫；后端未改，但仓库里同时还有另一路会话在改
  `student/*`、`App.tsx` 等文件，此时跑全量 Maven 的结果不能归因于本次改动，故未跑。
