# 参考：扇贝（shanbay）词卡配图的做法（2026-10-30）

用户截图里 `purchase` 的配图（`vocab_purchase_20251128_112258.png`），我们拆了一遍它的实现，用来对标我们自己的 `final-v2` 暖纸底方案。

## 实测拆解

| 项 | 扇贝这张 | 我们的 final-v2（C1） |
| :--- | :--- | :--- |
| 画布 | **300×282**，RGBA | 512×512，RGB |
| **背景** | **约 37% 像素透明**（alpha<10），图直接盖在页面浅灰面板上 | 不透明，暖纸底（L≈196，近白像素 0.4%） |
| 页面面板色 | 插图区边缘 ≈ `#E6E7E7`；卡片其它处 `#FCFCFC`/`#FFFFFF` | 卡片 `--panel-2`（浅色） |
| 线条 | 细黑描边（`#000`，占不透明像素 9.5%） | 无描边，靠色块边缘 |
| 配色 | 平涂、低饱和：青灰 `#90B8C0`/`#A0C0C0`、芥末黄 `#C0B038` | 水彩纸纹 + 暖黄 |
| 纹理 | **无**（纯平涂） | 纸纹 + 笔刷边缘 |
| 留白 | 主体占画面 ~55%，四周大量空白 | 主体 ~60%，暖底铺满 |

结论：**扇贝好看的关键不是“更亮”，而是「透明背景 + 浅灰面板 + 细线平涂」**——纯白之所以“亮瞎眼”，是因为我们把白底烤进了图里，图与卡片之间没有层次；他们靠 alpha 让面板色透出来，天然有边界。

## 我们要「剽」的三件事

1. **去掉烤死的白/纸底**：生成后用白底转 alpha（线描图边缘干净，阈值可用 245–250），输出 **透明 PNG/WebP**；
2. **卡片侧给一层浅灰面板**：`--panel-2` 上面再叠一个 `#F1F2F1`~`#E9EAE9` 的圆角块（或直接给插图容器一个浅灰底），让线描图浮起来；
3. **画风换成细线平涂**：细黑描边 + 2–3 个低饱和色 + 无纹理，取代水彩纸纹。

## 新风格提示词（S1，待验证）

```text
single-subject line illustration, thin black ink outlines, flat muted fills in teal and mustard,
no shading, no gradients, no texture, generous empty space, centered composition,
plain near-white background, no text, no letters, no watermark:
{scene}
```

后处理：`levels 2%–98%` → 白底（≥247）转 alpha → 缩到 176/96 → 轻锐化；**不做**暖色偏移、**不做**高光压缩。

## 待验证的问题

- Flux 出的线描边缘是否干净到可以直接抠 alpha（水彩版边缘有渐变，抠出来会有毛边）；
- 抠图后主体太小/太大时的裁切策略；
- 透明 WebP 在 88px 下的可读性（对比我们的不透明暖底）。
