# 共用材料只渲染一次（T321，2026-10-21）

## 改了什么

- 后端 `MaterialGrouper`：在考试快照上识别「阅读材料组」与「完形/语法填空空组」，
  `GET /api/offerings/{id}/paper` 的每题多返回 `groupKey / material / questionStem / blankIndex`。
  材料只在组内第一条带上；分组任一项校验不过，整组退回现状（每题自带题干）。
- 前端 `ExamPaper`：按组渲染。
  - 阅读：材料只出现一次，下面列题目；
  - 完形/七选五：材料一次，空在原文里；点空弹出 A–D（七选五为 A–G），可标记/清除；
  - 语法填空：材料一次，空是行内输入框，旁边有旗标标记；
  - 目录树、滚动联动、已答/标记、提交检查仍按原题号。
- `ExamLivePage`：滚动联动改成「同一材料组内保留当前空，跨组跟随新段首」；
  点目录树里的空会滚过去、聚焦并打开选项弹层。
