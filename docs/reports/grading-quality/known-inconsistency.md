1. 保留原始 review 文件与 git 历史；
2. 在 golden set 评估脚本里按用户拍板的政策生成「更正参考」（JZ 10/10），
   报告里同时给出「原参考 / 更正参考 / 边界标记」三列；
3. `class_summary.txt` 的「JZ/Mark 超出篇幅」改为「Mark 超出篇幅；JZ 在政策下为 4 段」；
4. 任何未来对长度政策的修改，都要重新出这份说明，不覆盖历史。
