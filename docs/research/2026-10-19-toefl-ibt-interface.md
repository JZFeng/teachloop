# 托福 iBT 在线考试界面：可借鉴的做法

日期：2026-10-19　用途：为「学生考试视图（US-21）」找外部参照

## 已核实的事实

来源一：新东方网《全是细节！新版托福考试界面曝光》(2023-06-04)
URL: https://mtoutiao.xdf.cn/toefl/202306/13340491.html

1. **阅读界面从「左题右文章」改为「左文章右题目」**，与 GRE 一致。这是 2023-07-26 改版中界面层面最大的变化。
2. 阅读取消加试后为 2 篇 20 题；官方宣传 35 分钟，实测计时为 **36 分钟**。
3. 写作顺序：先综合写作（20 分钟），再学术讨论写作（**10 分钟，读材料 + 写作合并计时**）。
4. 口语试音页有 Too Quiet / Good / Too Loud 三档音量示意，需点 check level 才可继续。

来源二：新东方在线《7月26日托福改革首考经验分享》(2023-07-27)
URL: https://m.koolearn.com/toefl/20230727/856170.html

5. 界面**配色收敛为白色 + 少量绿色**，比旧版更简洁。
6. **instructions 与 directions 不再是长篇大论**，各部分衔接更简短，甚至不点 continue 也会较快进入下一部分。
7. 阅读：**左边是文章，右边是题目**；两篇文章 20 题，倒计时 36 分钟。
8. 听力：旧版「先点 OK 再点 Next」被取消，**只剩 Next**，点一下直接进下一题。
9. 口语第 2、3 题在 instruction 阶段，材料先以**马赛克**呈现（看不清），答题时才露出。

## 本次未核实（凭记忆，不得当作依据）

- 阅读/听力是否有「Review」屏列出全部题号与作答状态、可跳回
- 是否有 Mark for review 标记
- 写作界面是否显示实时字数统计
- 倒计时最后 5 分钟是否变红/闪烁

以上四项若要采纳，需先核实再写进设计。

## 对照我们的考试视图（US-21）

| 托福做法 | 我们的做法 | 判断 |
|---|---|---|
| 阅读左文章右题目（2023 改版选的方案） | 试卷 inline 长卷，作答控件内嵌 | 场景不同：托福阅读的文章是**参考资料**（要反复回读找证据），题目是一次性的；我们的完形填空文章本身就是**作答载体**。前者可分栏，后者必须 inline |
| 界面不断收敛、白 + 少量绿 | 四套主题可切 | 考试页应默认收敛，主题切换在考试时保留但默认关闭 |
| instructions 简短、自动进入 | 有部分分隔标题 | 可借鉴：考试页不放大段说明 |
| 听力只有 Next | 长卷无 Next 概念 | 不适用 |
| 口语材料先打码 | 无 | 可借鉴：分部分发卷 / 听力先播放后显示题目 |
| 写作计时为「读材料 + 写」合并 | 写作是一个 textarea | 可借鉴：写作若要限时，计时从看到材料起算 |
