## 1. 摘要

前端有 24 条路由、37 个 `.tsx`、4 个手写 CSS 文件（952 行）与 271 处内联样式，
但**没有组件层，也没有任何样式守卫**：127 处手写 `className="btn…"`，
`.btn` 连 `:disabled` 都是后来补的。本特性建立三层：

| 层 | 作用 | 落点 |
| :--- | :--- | :--- |
| 令牌层 | 颜色/字号/圆角/阴影的唯一真源，亮暗两套 | `web/src/ui/tokens.ts`、`web/src/styles/tokens.css` |
| 组件层 | 页面只从这里引组件，状态齐全 | `web/src/ui/` |
| 守卫层 | 写错就失败 | `scripts/check-ui.py`、`scripts/ui/contrast.py`、`make check-ui` |

视觉方向按用户决策：**教育行业稳重**（蓝主色 #1D5FBF、实边框、更高密度），
组件库用 **Ant Design 6.6.7**，主题保留**亮/暗两套**，先迁移 **5 个高频屏**。

### 1.1 关键设计立场

| 议题 | 立场 | 理由 |
| :--- | :--- | :--- |
| 未迁移的 13 屏 | **靠令牌层自动继承新视觉**，不逐屏重写 | 21 屏里 13 屏不该等改造；旧变量指向新值，一改全变 |
| 令牌写两处 | 接受重复，但脚本断言两处相等 | antd 的 CSS 变量按组件元素注入，`:root` 里 `var(--ant-*)` 会失效，只能各写一份 |
| 组件库版本 | antd 6（不是 5） | React 19.3 下 v6 原生支持，不需要 v5 的 patch 包 |
| 主按钮 | 实色，**去掉渐变与彩色投影** | 紫渐变色 + 彩色投影是 2021 模板审美的主要来源 |
| 表头 | 去掉 `text-transform:uppercase` | 对中文无效，只让英文整齐 |
| 图标 | `@ant-design/icons`，禁止 emoji | emoji 字重/色彩/基线因系统而异 |
| 主题开关 | 默认亮色 + 手动切换，存本机 | 教室投影时被系统偏好切成暗色无法解释 |

## 2. 用户故事

### US-27 作为教师，我看到的界面是一致的，不再每屏一个样

同一类操作在登录页、首页、列表页长得一样；主色只有一个；表格密度一致；侧栏每个入口都有统一来源的图标。
**验收**：见 AC-27.1–27.6。

### US-28 作为开发者，我加新页面时不用再自己拼样式

有 Button / Field / Table / Tag / States 可用，且每个都有禁用、加载、焦点态。
**验收**：见 AC-28.1–28.3。

### US-29 作为用键盘或在强光下用设备的用户，我能看清也能操作

对比度达标，焦点环可见，Tab 能走完主流程，弹层用键盘能关。
**验收**：见 AC-29.1–29.4。

### US-30 作为项目维护者，我知道标准不会在下一次改动里悄悄走样

写死颜色、直接引 antd、手写 btn 类名会让 `make test` 失败。
**验收**：见 AC-30.1–30.3。

### US-68 作为教师/学生，我看不出哪个页面用的是哪一套表格

> 编号说明（2026-10-25）：US-31 起、FR-062 起、T360 起的号已被 `specs/006-brand-visual` 与
> `specs/002-v2-platform` 占用，新开条目按**全局最大号顺延**（US-68、AC-68.1–68.6、FR-138–141、
> T441–446），避免在 `AGENTS.md` 交付前自检里新增重复编号。

所有列表页的表格来自**同一个组件**：排序、分页、每页条数、空态、选择列的行为一致；
只有「我的词库」额外提供列配置。**验收**：见 AC-68.1–68.6。

### US-70 作为用户，我一眼能分出「出错了」「有风险」「只是说明」

> 编号说明（2026-10-25）：接 US-68 之后按全局最大号顺延（US-70、AC-70.1–70.4、FR-151–152），
> 与 `specs/006-brand-visual`（US-31–67）、`specs/002-v2-platform`（FR-062–137）不重号。

失败与阻断不再是一行灰字：**红**=操作失败或被拦住，**黄**=还能继续但有风险或有事待办，
**绿**=刚完成且有时效，**蓝/中性**=纯说明。判据写在 `docs/decisions/026-message-tones.md`。
**验收**：见 AC-70.1–70.4。

### US-71 作为教师，长解释不占屏，需要时再展开

一屏十几个字段、每个字段下面两行灰字，真正要填的输入框反而被埋起来。长解释收进标签旁的 ⓘ，
页面只留「这是什么」；自解释的句子直接删，不折进气泡。
**验收**：见 AC-71.1–71.4。

### US-72 作为学生，首页告诉我「现在该点什么」，不是把同一句话说四遍

> 编号说明（2026-10-26）：接全局最大号顺延（US-72、AC-72.1–72.5、FR-154、T499）。

2026-10-26 用户报：学生首页「`DASHBOARD` / 我的学习 / 考试、作业与反馈；成绩由老师公布后可见」
四层标签在说同一件事，而「看评语」这个唯一有用的动作被做成了页头按钮——它跟侧栏重名、指向同一份列表，
真正有评语的那一行里那枚「有反馈」却点不动。原则：**页头只说一次这是什么；动作放在出现证据的那一行。**
**验收**：见 AC-72.1–72.5。
