# 规格说明 — 背单词与间隔重复（004-vocab）

- 特性编号：`004-vocab`
- 状态：**规格草案，待用户 review**（用户故事 + 验收标准 + 功能需求）
- 上游：`specs/004-vocab/source-requirements.md`（外部需求抽取）、`docs/decisions/011-vocab-requirements.md`（本期决策）、宪法第十四条（模块边界）与第十五条（UI）
- 日期：2026-10-23
- 下游：mock ⇄ spec 循环 → plan（6 条清单）→ tasks

---

## 1. 摘要

给 TeachLoop 增加一层「背单词」，主用例是**老师课前把下一节课的生词发给班级，学生提前预习**，
词进入学生的**总词汇库**并按间隔重复排复习。

与外部需求文档的关键差异（详见决策 011）：

| 议题 | 外部文档 | 本规格 | 原因 |
| :--- | :--- | :--- | :--- |
| 库的结构 | 每个用户多个卡组，卡片属于卡组 | **一个总库** + 卡组是「保存的筛选」，不拥有卡片 | 课程按学期增长，卡组当容器会爆炸；同一个词会被背多遍 |
| 进度唯一性 | 进度挂在 `(user, card)`，卡片可重复 | 进度按 `(学生, 词条)` **唯一** | 同一个词从几门课进来也只有一份进度 |
| 账号 | 注册/手机验证码/双 Token | 复用 TeachLoop 身份模块 | 用户 2026-10-23 确认 |
| 老师发词 | 无 | **第一期就做**（词集 × 班级 × 截止时间，发送时快照） | 主用例 |
| 算法 | SM-2 公式 | 可替换策略，默认 SM-2；参数见 §5 | 用户 2026-10-23 选择 |

本期做：卡片 / 词库 / 卡组视图 / 批量导入 / 教师词集 / 发词给班级 / 今日复习 / 四级评分调度。

## 2. 角色

| 角色 | 能做 | 不能做 |
| :--- | :--- | :--- |
| **学生** | 维护自己的词库（加词、导入、改个人笔记与标签）、建少量卡组视图、领取班级生词、按队列复习并评分 | 看他人词库；改教师词集的词条内容；看未发给自己的词集 |
| **教师** | 建/改/删自己的词集、把词集发给自己带的班（可设截止时间）、重复发同一词集 | 看学生词库与背诵明细（本期）；发给自己不带的班 |
| **管理员** | 沿用现有能力（不新增） | — |

账号、登录、资料补全、CSRF、限流全部复用现有身份模块（宪法第十四条允许 vocab 依赖 `shared / identity / classroom`）。

## 3. 用户故事与验收标准

### US-46 学生建立与维护自己的词库

> 学生要能把词加进来，并且**一个词只有一条**，不管它从哪儿来。

- [ ] AC-46.1 学生侧有一级导航入口，进「我的词库」；空库显示空态并给两个入口（手动加词、批量导入）。**空态时「班级发来的生词」横幅仍然显示**——新用户第一眼靠它找到内容入口。
- [ ] AC-46.2 手动加词表单：正面必填（≤64 字符）、释义必填；发音、例句（可多条）、构词分析、笔记、标签（多个）可选；保存后立即出现在列表首行，无需刷新。
- [ ] AC-46.3 添加一个规范化后已存在的词（规范化见 FR-093）时不新建词条：提示「已在词库（来源：X）」，仅更新个人层（笔记/标签/收藏）。
- [ ] AC-46.4 列表支持：搜索（正面/释义）、按来源筛选（全部 / 某次布置 / 某次导入 / 自己添加）、按卡组视图筛选、分页（20/50/100）。**搜索框固定在列表上方、滚动时始终可见（sticky）**，并承担两个语义：
  - 输入时：实时筛选「我的词库」；
  - 按 **Enter**：打开该词的详情页（在库的词进自己的详情；**不在库的词直接查本地词表**并进详情，详情页给「加入词库」）。
  **默认排序 = 下次复习时间升序**（新词与到期词自然排在最前），不是字母序；点表头可按任意列排序。
- [ ] AC-46.5 学生可改自己创建词条的全部字段；来自教师词集的词条**内容只读**（正面、发音、释义、例句、构词），只可编辑个人层，并在界面上标注来源。

### US-47 卡组 = 保存的筛选条件，不是容器

> 防止「一学期几十个卡组」；卡组只回答「我要看哪一部分」。

- [ ] AC-47.1 学生可创建卡组视图，条件为以下各项的任意组合：来源、标签、学习状态（新词 / 学习中 / 复习中 / 已掌握）；保存后在词库侧栏出现。
- [ ] AC-47.2 一张卡同时命中多个卡组视图时，「今日复习」里**只出现一次**。
- [ ] AC-47.3 删除卡组视图不删除任何词条或进度；重建同条件视图后，数据与删除前一致。
- [ ] AC-47.4 单学生卡组视图数量上限默认 **20**，由 `teachloop.vocab.decks.max-per-student` 配置；达到上限时创建按钮禁用并说明原因，已有视图不受影响。
- [ ] AC-47.5 界面上不存在「把卡片移入/移出卡组」的操作；只有「编辑筛选条件」。

### US-48 批量导入单词

- [ ] AC-48.1 支持 `.csv` / `.md` / `.txt`（**三种必须支持**），`.xlsx` 为可选；单文件 ≤20MB；提交前先出**预览**：总行数、前 20 条、预计「新建 / 重复跳过 / 会失败」三个数。**纯词表（只有单词、没有释义）可以导**，不当作失败。
- [ ] AC-48.2 字段映射：有表头时才做列映射（正面必填映射，释义可选映射）；发音、例句、构词分析、笔记、标签、卡组名可选；匹配不到时在预览页手动选列。**无表头的纯词表**跳过映射，直接按 FR-108 的切分规则解析。**「批量导入文件」与「粘贴文本加词」是同一个动作的两种输入**：都只做「把词加进词表」，提交后走同一条异步生成管线，结果一致。
- [ ] AC-48.3 **导入/加词只负责入库，内容异步生成**：提交后立刻能看到这些词（词形、来源、语言），释义/例句/构词/词族由后台异步生成；**已存在的词不重复生成**；生成中、生成成功、生成失败三种状态在列表可见；失败可单条或批量重试。
- [ ] AC-48.4 入库即可进入调度：新词当天进队列；若内容尚未生成完，卡片显示「内容生成中」并允许跳过，**不阻塞**；超过 24 小时仍失败则标「内容缺失」、移出队列并在词库提醒。
- [ ] AC-48.3 导入完成后给出：成功 N 条、重复跳过 M 条、失败 K 条；失败逐条给**行号 + 原值片段 + 原因**（如「第 55 行：缺少释义」）。
- [ ] AC-48.4 1000 行文件能导入成功，且服务端峰值堆内存不随行数线性增长（验收：1000 行与 10000 行各跑一次，峰值增长 ≤50%）。
- [ ] AC-48.5 行内带卡组名时自动匹配同名卡组视图，不存在则创建；若已达 AC-47.4 的上限，**导入继续**，该批不打视图并明确提示。
- [ ] AC-48.6 导入时可选一个来源标记（如「Unit 5 生词」），之后能按该来源筛选与组卷复习。
- [ ] AC-48.7 文件编码兼容 UTF-8 与带 BOM 的 UTF-8；其他编码给出明确报错，不静默乱码。

### US-49 教师维护词集（列表 = 表格 + 编辑页）

- [ ] AC-49.1 教师侧有一级导航入口，进「词集」；**页面是表格视图，一行一个词集**，
      列为：`名称 / 学习语言 / 词数 / 状态（启用·停用）/ 已发给几个班 / 更新时间 / 操作`。
- [ ] AC-49.2 每行最左有复选框，表头有全选；选中后出现批量操作条：**启用 / 停用 / 删除**（二次确认，显示将影响 N 个词集）。
      「更新」在每行操作列，是单行动作（进入编辑页）。
- [ ] AC-49.3 点词集名称或「更新」进入 **new / update 编辑页**：名称、学习语言、说明、状态、词条列表（可调顺序、可移除）。
- [ ] AC-49.4 **「导入单词」与「加词」只在编辑页**，列表页不出现这两个按钮；新建后再往里放词。
- [ ] AC-49.5 停用的词集不能再被发词，但仍能看到历史发词记录；已发出的布置不受影响。
- [ ] AC-49.6 词集可复用：同一条词集能反复布置，不需要复制出新词集。
- [ ] AC-49.7 词条顺序即学生首次预习时的呈现顺序。
- [ ] AC-49.8 删除词集不影响已发出的布置（布置是快照），也不影响学生已领的词。
- [ ] AC-49.9 词集里的「移除」只把词**移出该词集**：不删除词条、不影响学生已领的词与复习进度；编辑页要示意这一点。

### US-50 教师把词集发给班级

- [ ] AC-50.1 一次发词 = 选词集 + 选一个或多个**自己带的班** + 可选截止时间 + 可选说明。
  - **词集选择器是可输入搜索的下拉**（输入即过滤，候选显示词数与已发班级数）；只列启用状态的词集。
  - **班级选择器是分组 chip 面板**：按年级分组、每个班显示人数、带搜索框、每组有「本年级全选」、顶部有「全选 / 清空」，
    并实时显示「已选 N 个班 · 预计 M 名学生」。18 个班时面板内滚动（2026-10-23 用户选定此形态）。
  - 说明性内容（学生端会看到什么、发送后发生什么）**不占版面**，收进 ⓘ 气泡。
- [ ] AC-50.2 发送时对词集内容做**快照**；之后修改词集会提示「已发出的 N 次布置不受影响」，学生端内容不变。
- [ ] AC-50.3 同一词集对同一班重复发：学生已领的词不重复入库，只追加来源并更新截止时间。
- [ ] AC-50.4 发给不带的班返回 404（不泄露班级是否存在）；未登录返回 401。前端对非本人班级**灰显并标注「非本人班级」、不可选**，且不发起请求。
- [ ] AC-50.5 学生端第一屏出现待办横幅「待预习：Unit 5 生词 · 3 天后截止」，点击进入该次布置的预习页；无待办时不显示。**V1 的位置是词库页顶部横幅**（mock 采用），独立首页的待办区块留到有首页时再放（2026-10-23 记）。

### US-51 学生领取班级生词

- [ ] AC-51.1 预习页展示词集内容（按教师设定顺序）；点「加入我的词库」后词条入库并标记来源（哪次布置、哪个班、哪位老师）。
- [ ] AC-51.2 已在库的词只追加来源标记，不新建词条、不重置进度。
- [ ] AC-51.3 过了截止时间仍可加入，列表标「已过期」；过期不影响入库。
- [ ] AC-51.4 学生退班后，已入库的词与进度保留，来源显示原班级名。

### US-52 今日复习队列

- [ ] AC-52.1 队列 = 到期时间 ≤ 当前时间 的词，按到期时间升序；可按卡组视图或来源收窄。
- [ ] AC-52.2 队列页显示三个数并写字面口径：今日已复习 N 张（今天已评分的次数）、剩余待复习 M 张（今天到期且已到时间）、本次新卡 K 张（今天首次进队列）。**这三个数与「评分会改变什么」这类说明性内容不占页面版面**，收进进度条旁的 ⓘ 气泡，点开才显示。
- [ ] AC-52.3 每日新卡上限默认 **20**，由 `teachloop.vocab.review.daily-new-cards` 配置；超出部分次日再进队列，并显示「今天的新卡已用完」。
- [ ] AC-52.4 到期卡不限量，但单次最多加载 100 张，滚动到末尾自动加载更多。
- [ ] AC-52.5 空队列有明确空态「今天没有要复习的卡」，并给「去词库加词」入口。
- [ ] AC-52.6 队列里每张卡只出现一次（与 AC-47.2 一致），即使它同时属于多个卡组视图。

### US-53 四级评分与间隔调度

- [ ] AC-53.1 复习页正面显示单词与发音；翻面（点击卡片或空格）后显示释义、例句、构词分析、个人笔记。
- [ ] AC-53.2 只有**两个**评分按钮：**不认识 / 认识**，每个都显示下次间隔（如「5 分钟后再来」「1 天后再来」）；键盘 `1` / `2` 等价。按钮**任何时候都可点**（不必先翻面）。
  - 点「**认识**」→ 记录「良好」并**立即进入下一个词**；
  - 点「**不认识**」→ 记录「忘记」并**自动把卡片翻面**（展示释义、例句、构词、笔记），**停在当前词**，由用户看完后点「下一个 →」继续；
  - 同一张卡**只能评一次**：评过之后两个按钮置灰，直到切到下一张；
  - 点击卡片本身是「手动翻面」，只展示内容、不产生评分。
- [ ] AC-53.3 每次评分写入一条复习日志（词条、评分、时间、可选耗时）；「认识」评分后立即进入下一张，「不认识」评分后翻面停留。
- [ ] AC-53.7 复习页只有**「下一个」**，**悬浮在卡片右侧**：未评分时半透明（可跳过），翻面后（点了「不认识」）变为高亮主按钮；快捷键 **`N`** 与 **`→`** 等价。**不提供「上一个」，也不提供撤销**（2026-10-23 用户决定：简化逻辑）。
- [ ] AC-53.4 按 §5 的表更新该词进度（状态、到期时间、间隔、易度）；该词下次出现的时间与表一致。**两档评分到内部调度参数的映射见 §5 与 §17（待讨论）**，实现时先按默认映射落地。
- [ ] AC-53.5 调度决策来自**可替换策略**，默认 SM-2；验收判定以「默认策略」为准，换策略不改表结构。
- [ ] AC-53.6 提交失败（断网/5xx）时停留在当前卡并提示重试；不前进、不重复记日志（同一次提交带幂等标识）。

### US-54 归属、越权与隐私

- [ ] AC-54.1 学生只能看到自己的词库、卡组视图、复习记录；访问他人资源返回 404。
- [ ] AC-54.2 教师只能看到自己创建的词集与自己发出的布置。
- [ ] AC-54.3 本期不向教师返回任何学生背诵明细（接口层面不返回，不是前端隐藏）。
- [ ] AC-54.4 审计与运行日志不写词条正文、释义、例句与个人笔记（宪法第七条）。

### US-55 删除、保留与恢复

- [ ] AC-55.1 删除词条为软删除：不再出现在列表、队列、统计中；历史复习记录保留。
- [ ] AC-55.2 删除卡组视图不删词；删除布置不删学生已领的词。
- [ ] AC-55.3 已删除的词再次通过导入或布置进来时，**恢复原词条与原进度**，不新建。

### US-56 界面状态与文案

- [ ] AC-56.1 每个新页面都具备：空白态、有数据态、加载态、出错态（含重试）。
- [ ] AC-56.2 新增界面文案全部进 `web/src/locales/zh-CN.json` 与 `en.json`，键集对齐；组件内不出现中文字面量（`make check-i18n` 退出码 0）。
- [ ] AC-56.3 导航按宪法第十五条上线即用，不放占位空承诺；**学生新增两个一级导航项（我的词库 / 今日复习），教师新增两个（词集 / 发词）**（教师入口不塞进班级页）。2026-10-23 由「各一个」修正为实际形态。

### US-57 单词发音（TTS）

> 不会读的词背了也没用。发音要能听见，且不能因为一次外部调用失败就让复习卡住。

- [ ] AC-57.1 复习页正面、词库详情、词集详情三处都有喇叭按钮；点击朗读当前单词，播放中按钮呈加载态，可再次点击停止。
- [ ] AC-57.2 音频按「词条 + 音色 + 语速」的内容哈希缓存到**部署的存储**（开发是本机 `./uploads`，生产是 OSS；不进 git、不进 jar、不入数据库 BLOB，数据库只存键与元数据）；同一个词第二次播放**不再调用 TTS**，首播 p95 ≤1.5s，命中缓存 p95 ≤300ms，响应带长期缓存头。
- [ ] AC-57.3 提供商可替换：`tts.provider` 支持 `local`（默认）/ `cloud` / `browser`。回落链固定为 **缓存 → 本地引擎 → 浏览器语音**：本地引擎缺失或超过 2s 未返回时回落浏览器，并照常完成复习，不弹阻塞式错误。
- [ ] AC-57.4 生成失败与回落都要留可观测痕迹（计数 + 审计），但不记录词条正文以外的用户数据。
- [ ] AC-57.5 若启用 `cloud`：凭据走现有 `/admin/ai` 配置方式（加密存储、掩码回显），不在前端暴露。
- [ ] AC-57.6 **只朗读单词本身**，不朗读释义、例句与笔记；例句朗读明确不在本期（§9）。

### US-58 学习语言可扩展（不只英语）

> 以后可能用同一套系统学中文和西班牙语，所以「学习语言」必须是数据属性，不是写死在代码里的英语假设。

- [ ] AC-58.1 每条词条带**学习语言**（`en` / `zh` / `es` …，可扩展）；导入、手动加词、发词都记录语言。
- [ ] AC-58.2 词库默认只显示**当前学习语言**的词；切换学习语言后列表、复习队列、统计随之切换，互不串味。
- [ ] AC-58.3 界面语言（中/英）与学习语言是两件事：界面用英文时也能背中文词，两者互不影响。
- [ ] AC-58.4 V1 只提供 `en` 的词表与发音；`zh` / `es` 的 TTS 音色与数据留到后续，但表结构与接口不因新增语言而改。

### US-59 词库表格：排序、列自定义、筛选与批量标记

> 词库是学生批处理的主战场，不是一个只读列表。

- [ ] AC-59.1 每行最左有**复选框**；表头有全选；选中 ≥1 行后出现批量操作条，可**批量「移出复习」**（二次确认，显示将影响 N 个词）。
- [ ] AC-59.2 每行右侧有**「移出复习」按钮**，单条操作；移出后该词立刻从「今日复习」与「到期」统计里消失，状态显示「已移出」；**词仍在词库、仍可搜索到**，行内按钮变为「重新加入」。
- [ ] AC-59.3 **重新加入 = 回到生词本**：状态回到「新词」，当天进入队列重新开始排期；历史复习日志保留，不删除记录。
- [ ] AC-59.4 点击单词（非复选框区域）进入**单词详情页**；详情页与复习页共用同一套模板（US-60）。
- [ ] AC-59.5 列可自定义：可勾选显示哪些列、可拖动调整列顺序；配置按学生保存，下次打开沿用。
- [ ] AC-59.6 默认列（按此顺序）：**单词 / 释义 / 来源 / 状态 / 下次复习 / 操作**；默认排序 = 下次复习时间升序。
- [ ] AC-59.7 点表头可按该列排序（升/降切换），排序在分页之上生效（不是只排当前页）。
- [ ] AC-59.8 表格上方的统计卡**可点击过滤**：点「今天到期」只看今天到期，点「新词」只看新词，点「已掌握」只看已掌握；再点一次取消。当前生效的过滤要在卡片上有可见选中态。
- [ ] AC-59.9 工具条有**「筛选」按钮**，点击打开弹窗（modal），可在其中组合：**来源（多选，多个取并集，不选 = 全部）**、**卡组视图**、学习状态、标签、语言；弹窗底部「应用 / 重置」，应用后列表与统计同步，按钮上显示生效条件数。**工具条上不再放「全部 / 易错」这类视图切换**——视图统一进筛选弹窗。
- [ ] AC-59.10 过滤条件要能出现在 URL 上（刷新与分享后仍生效）。

### US-60 单词详情页（模板化 + 可预生成）

> 同一个单词的详情页长得一样，只是数据不同；所以它应该是一份模板 + 一份 JSON。

- [ ] AC-60.1 详情页内容：单词与**英式/美式音标**（各带发音按钮）、释义（按词性分组）、例句（含中文翻译）、构词分析、**word family**（同族词，带词频标记）、笔记、来源标签。
- [ ] AC-60.2 右上角的动作随「是否在库」变化：
  - **不在库**：显示「＋ 加入词库」；点击后入库、进入「新词」队列（今天可复习），内容异步生成；
  - **在库**：显示 favourite 收藏开关 +「重新加入生词本」+「移出复习」。
  「重新加入生词本」对**任何在库的词**都可用（包括误点后想重来的），效果是重置为新词、日志保留；需二次确认。
- [ ] AC-60.3 详情页的 **remove 与词库的「移出复习」是同一个动作**：以后不再安排这个词复习；词仍在库、可搜索；状态显示「已移出」，可一键「重新加入生词本」（回到新词、当天可复习、历史保留）。
- [ ] AC-60.8 详情页**不提供撤销上一次评分**（2026-10-23 决定）；误点的官方路径是「搜索该词 → 详情 → 重新加入生词本」（进度归零、日志保留），在页面上要有文案说明这一点。
- [ ] AC-60.4 页面提供 **feedback 入口**；提交时带上**当前单词的 JSON**（不是只带 word id），便于定位内容问题。
- [ ] AC-60.5 详情页是**模板 + JSON**：同一份 HTML 模板渲染不同单词，不允许每个词一个页面文件。
- [ ] AC-60.6 页面内容允许**预生成为静态 HTML**（如 `word/{lang}/{word}.html`），存在时由反向代理直接返回；不存在时异步生成，**生成期间页面先用模板 + 实时 JSON 渲染**，不阻塞用户。是否存在由 Bloom filter 做前置判断（只用于「一定没有」的快速否定，最终以存储为准）。
- [ ] AC-60.7 **词族数据本地优先**：命中本地词表（Paul Nation word family 表）时直接显示同族词与频段，按频次降序、排除当前词、最多 N 个（默认 8，可配置）；未命中的词由异步生成补上并回填，下次直接命中。命中时显示频段标签（如「BNC 第 3 千词族」），未命中时不编造频段。

### US-61 词库内自由复习（不受到期限制）

> 学生经常这样用：打开一个词集从头过一遍，会的直接标掉；或者干脆把 1000 个词全过一遍，过到第 500 个没时间了就停。

- [ ] AC-61.1 词库与词集页都有**「开始复习」入口**，范围 = **当前筛选条件命中的全部词**（不是当前页显示的那几行），不受到期时间与每日新卡上限限制；**状态为「已移出复习」的词自动排除**，按钮上的数量就是排除后的可复习数。
- [ ] AC-61.2 自由复习的每张卡除四级评分外，多一个**「已熟悉」**按钮（快捷键 `S`）：点了直接标为已掌握并跳到下一张，不参与 SRS 计算。
- [ ] AC-61.3 随时可以**结束复习**：结束页显示本次看了多少、标熟悉多少、评分分布；未看的词保持原状态不变。
- [ ] AC-61.4 **进度可续**：下次从同一范围再次开始时，默认从「上次停留的位置」继续，并显示「上次看到第 501 / 1000」；也可以选择从头开始。
- [ ] AC-61.5 自由复习是独立会话，不写入「今日复习」的完成数；但**「认识」按与今日复习相同的调度规则推进进度**（2026-10-23 定），「移出复习」会改变该词状态与统计。
- [ ] AC-61.6 复习结束页有明确的下一步：返回词库 / 继续复习剩余词 / 去看今日复习。

## 5. 调度参数（默认 SM-2 策略，本期取值）

参数集中一处、可调；调参不算改需求。表里标「源」的来自外部需求文档，标「补」的是文档没写、本项目补齐的。

> **界面只有两档（认识 / 不认识）**。下表仍是内部策略的四档参数；内部映射已定（2026-10-23）：**认识 → 3 良好，不认识 → 1 忘记**，改映射不动 UI。

| 评分 | 状态迁移 | 下次间隔 | 易度变化 |
| :--- | :--- | :--- | :--- |
| 1 忘记 | → 学习中 | **5 分钟**（源） | −0.20，下限 1.30（补；源只说「扣减」） |
| 2 困难 | → 学习中 | 旧间隔 ×1.2（源）；新词基线 10 分钟（补） | −0.15，下限 1.30（补） |
| 3 良好 | → 复习中 | max(1 天（补）, 旧间隔 × 易度（源）) | 不变（源） |
| 4 容易 | → 复习中 | max(4 天（补）, 旧间隔 × 易度 ×1.3（源）) | +0.15，上限 3.00（源：加、上限 3.0） |

- 新词初始：状态「新词」，易度 2.50（源），首次进队列当天到期。
- 毕业（补，源只说有 `GRADUATED` 状态）：连续 **4** 次「认识」且当前间隔 ≥**45 天** → 已掌握（2026-10-23 用户改：90 天太长）；
  已掌握的卡在间隔 ≥180 天时复查；任何一次「不认识」回到「学习中」。
- 每日新卡上限 20（补，源未定义）。

## 7. 边缘情况

| 情况 | 期望行为 |
| :--- | :--- |
| 同一个词先由教师发出、后被学生自己添加 | 只有一条词条；来源追加两条；内容以教师词集为准，个人层归学生 |
| 同一个词以不同大小写/全角进库 | 规范化后视为同一条，不新建 |
| 词集已发，教师改了其中某个词 | 已发出的布置保持快照内容；界面提示后续布置才生效 |
| 学生已退班，老师再次发同一词集 | 该学生不再收到待办；已入库的词与进度保留 |
| 卡组视图条件命中 0 个词 | 视图保留，显示空态，不自动删除 |
| 卡组视图达到上限时导入带卡组名 | 导入继续，该批不入视图，结果里明确列出该批 N 条未分组 |
| 导入文件只有一列 | 预览阶段就拦下，说明「至少需要正面与释义两列」，不产生半成品数据 |
| 导入行释义为空 | 该行失败并记录行号与原因，其余行继续 |
| 复习时网络中断 | 停在当前卡、提示重试；不前进、不重复记日志 |
| 同一天多次复习同一张卡（忘记后 5 分钟又来） | 允许；每次各记一条日志，进度按最后一次推进 |
| 学生时区与服务器不同 | 本期「今日」按部署时区（Asia/Shanghai）计算，发布说明中写明（见 A-3） |
| 删除词条后又从布置里领到同一个词 | 恢复原词条与原进度，不新建、不重置 |
| 教师在截止后才发词 | 允许，截止时间只用于学生端标记与待办 |

## 14. 词表数据源：本地词族表（Paul Nation）

详细实测与算法见 `docs/research/2026-10-23-vocab-wordlists-feasibility.md`。这里只列**不可协商的口径**。

### 14.1 数据与语义

| 项 | 口径 |
| :--- | :--- |
| 来源 | Paul Nation 的 BNC/COCA word family 表（用户本地目录，**原始 txt 不入库**） |
| 规模（实测） | 频段 1–30：**28,276 个词族 / 80,585 个词形**（去重 80,579）；另有专有名词 22,087 族、前缀表 50 项、学科词、缩写、法语借词 |
| 行格式 | 族首行无缩进，`族首词 + 族总频次`；成员行行首一个 Tab，`词形 + 该词形自身频次` |
| 族首数字含义 | **整个词族的总频次**（不是族首词自身频次）；族首词自身频次 = 族总频次 − 成员频次合计，为负时不显示 |
| 文件号含义 | 频段（`basewrd1` = 第 1 千词族，依此类推），用于「第 N 千词族」标签与排序 |

### 14.2 解析规则（必须全部满足，否则会出现静默错数据）

- 兼容 **LF 与 CRLF**；空行跳过。
- 以**行首是否有 Tab** 判断族首 / 成员，不靠空格数。
- 每行只取「第一个 token = 词」「最后一个 token = 频次」，中间空白忽略。
- 入库统一 **NFC + 小写 + 去首尾空格** 作为 `normalized_form`；同时保留原形用于展示。
- 另建一份**去变音符**索引（`ÉCLAT → eclat`），保证用户不打变音符也能命中。
- **不依赖文件内顺序**（源文件不是严格按字母或频次排序）。
- 重复词形按**频次高者**归属，并记录来源频段。
- 族频次低于某成员的噪声族（实测 3 个），展示时只给族频次、不给单形频次。

### 14.3 查找与回退

1. 精确查 `normalized_form`；2. 未命中查去变音符索引；3. 仍未命中 → 交给异步内容生成（FR-113），生成结果带词族并回填索引。

未命中时**不得编造频段**；页面只显示「词族待补全」。

### 14.4 展示

- 词族最多显示 **N 个（默认 8，`teachloop.vocab.word-family.max-members`）**，按成员频次降序，排除当前词。
- 命中时显示频段标签（如「BNC 第 3 千词族」）与族频次。
- 词族数据缺失不影响详情页其余内容渲染（降级为不显示该区块，不报错）。


## 15. 导入语法（含 `.md`）

样例已收进 `specs/004-vocab/fixtures/import/sample-4-formats.md`（用户的四种写法）。

### 15.1 行类型

| 行 | 处理 |
| :--- | :--- |
| 空行 | 跳过（不报错、不计数） |
| `# 标题` / `> 引用` | 当说明文字跳过，**计入「跳过行数」** |
| ```` ``` ```` 围栏 | 切换代码块状态；块内行按普通词行解析 |
| 表格行 `\| a \| b \|` | 按单元格切；**分隔行**（`---`）跳过；首个非分隔行当作表头 |
| 列表项 `- a` / `* a` / `1. a` / `1) a` | 去掉标记后按普通词行解析 |
| 普通行 | 按 FR-108 切分：逗号（中英文）、空白、分号；忽略空 token 与行尾分隔符 |

### 15.2 说明文字与「静默丢弃」

- 导入语言为 `en` 时，**含中日韩字符的行视为说明文字跳过**（样例里的「1 一行，逗号隔开」等四行即属此类）。
- 导入语言为 `zh` 时该规则反向：含**纯 ASCII 且无中文**的短行才可能是外语说明，需在预览页让用户确认。
- 任何被跳过的行都必须在预览里给出**行号 + 原文 + 跳过原因**（宪法：静默丢弃即缺陷）。

### 15.3 验收样例（已实测）

`sample-4-formats.md` 共 22 行，解析结果：**40 条 token → 去重后 10 个**，四行中文说明被跳过并在预览里列出。

| 段落 | 行数 | 解析出 |
| :--- | ---: | ---: |
| 1 一行逗号分隔 | 1 | 10 |
| 2 一行空格分隔 | 1 | 10 |
| 3 每行一个 | 10 | 10 |
| 4 多行逗号（含混排空格） | 4 | 10 |
| 说明文字 | 4 | 0（跳过并报告） |

### 15.4 其他规则

- 含空格的短语（`take off`）必须用引号或 CSV 保护，否则会被空格切开；预览页要提示这一点。
- 表格导入时，首行是表头，列映射按表头名匹配（AC-48.2）。
- 同一文件里重复出现的词只入库一次，预览里显示「重复 M 条」。

## 19. 误点之后怎么补救（2026-10-23 已定）

决定：**不做撤销**，用现成的入口救——「搜索该词 → 进详情 → 重新加入生词本」。

| 途径 | 效果 | 代价 |
| :--- | :--- | :--- |
| **搜索 → 详情 → 重新加入生词本** | 立刻回到「新词」，今天就能再复习 | 进度归零（间隔/易度重置），但不是删除历史日志 |
| 词库 → 详情 →「移出复习」再「重新加入」 | 同上，只是多一步 | 同上 |
| 等下次到期 | 什么都不用做 | 「认识」会按易度往后推，老词可能十几天后才回来 |
| 自由复习 | 立刻再练一遍 | 再评一次会继续往后推 |

补充两条容易误解的规则：

1. **「加词 / 导入」对已存在的词不做任何事**：命中去重后只提示「已在词库」，不会改进度——所以它救不了误点。
2. **搜索无匹配时按 Enter 直接进详情**：这是「查任意词」的入口，不在库的词在这里可以「加入词库」；在库的词在这里可以「重新加入生词本」。
