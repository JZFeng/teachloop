# 规格说明 — 背单词与间隔重复（004-vocab）

- 特性编号：`004-vocab`
- 状态：**规格草案，待用户 review**（用户故事 + 验收标准 + 功能需求）
- 上游：`specs/004-vocab/source-requirements.md`（外部需求抽取）、`docs/decisions/011-vocab-requirements.md`（本期决策）、宪法第十四条（模块边界）与第十五条（UI）
- 日期：2026-10-23
- 下游：mock ⇄ spec 循环 → plan（6 条清单）→ tasks

---

## 1. 摘要

给 TeachLoop 增加一层「背单词」，主用例是**老师课前把下一节课的生词发给班级，学生提前预习**，
词进入学生的**总词汇库**并按间隔重复排复习。

与外部需求文档的关键差异（详见决策 011）：

| 议题 | 外部文档 | 本规格 | 原因 |
| :--- | :--- | :--- | :--- |
| 库的结构 | 每个用户多个卡组，卡片属于卡组 | **一个总库** + 卡组是「保存的筛选」，不拥有卡片 | 课程按学期增长，卡组当容器会爆炸；同一个词会被背多遍 |
| 进度唯一性 | 进度挂在 `(user, card)`，卡片可重复 | 进度按 `(学生, 词条)` **唯一** | 同一个词从几门课进来也只有一份进度 |
| 账号 | 注册/手机验证码/双 Token | 复用 TeachLoop 身份模块 | 用户 2026-10-23 确认 |
| 老师发词 | 无 | **第一期就做**（词集 × 班级 × 截止时间，发送时快照） | 主用例 |
| 算法 | SM-2 公式 | 可替换策略，默认 SM-2；参数见 §5 | 用户 2026-10-23 选择 |

本期做：卡片 / 词库 / 卡组视图 / 批量导入 / 教师词集 / 发词给班级 / 今日复习 / 四级评分调度。

## 2. 角色

| 角色 | 能做 | 不能做 |
| :--- | :--- | :--- |
| **学生** | 维护自己的词库（加词、导入、改个人笔记与标签）、建少量卡组视图、领取班级生词、按队列复习并评分 | 看他人词库；改教师词集的词条内容；看未发给自己的词集 |
| **教师** | 建/改/删自己的词集、把词集发给自己带的班（可设截止时间）、重复发同一词集 | 看学生词库与背诵明细（本期）；发给自己不带的班 |
| **管理员** | 沿用现有能力（不新增） | — |

账号、登录、资料补全、CSRF、限流全部复用现有身份模块（宪法第十四条允许 vocab 依赖 `shared / identity / classroom`）。

## 3. 用户故事与验收标准

### US-34 学生建立与维护自己的词库

> 学生要能把词加进来，并且**一个词只有一条**，不管它从哪儿来。

- [ ] AC-34.1 学生侧有一级导航入口，进「我的词库」；空库显示空态，并给两个入口：手动加词、批量导入。
- [ ] AC-34.2 手动加词表单：正面必填（≤64 字符）、释义必填；发音、例句（可多条）、构词分析、笔记、标签（多个）可选；保存后立即出现在列表首行，无需刷新。
- [ ] AC-34.3 添加一个规范化后已存在的词（规范化见 FR-089）时不新建词条：提示「已在词库（来源：X）」，仅更新个人层（笔记/标签/收藏）。
- [ ] AC-34.4 列表支持：搜索（正面/释义）、按来源筛选（全部 / 某次布置 / 某次导入 / 自己添加）、按卡组视图筛选、按到期时间或字母排序、分页（20/50/100）。
- [ ] AC-34.5 学生可改自己创建词条的全部字段；来自教师词集的词条**内容只读**（正面、发音、释义、例句、构词），只可编辑个人层，并在界面上标注来源。

### US-35 卡组 = 保存的筛选条件，不是容器

> 防止「一学期几十个卡组」；卡组只回答「我要看哪一部分」。

- [ ] AC-35.1 学生可创建卡组视图，条件为以下各项的任意组合：来源、标签、学习状态（新词 / 学习中 / 复习中 / 已掌握）；保存后在词库侧栏出现。
- [ ] AC-35.2 一张卡同时命中多个卡组视图时，「今日复习」里**只出现一次**。
- [ ] AC-35.3 删除卡组视图不删除任何词条或进度；重建同条件视图后，数据与删除前一致。
- [ ] AC-35.4 单学生卡组视图数量上限默认 **20**（可配置）；达到上限时创建按钮禁用并说明原因，已有视图不受影响。
- [ ] AC-35.5 界面上不存在「把卡片移入/移出卡组」的操作；只有「编辑筛选条件」。

### US-36 批量导入单词

- [ ] AC-36.1 支持 `.csv` / `.txt` / `.xlsx`，单文件 ≤20MB；选择文件后先出**预览**：总行数、前 20 条、预计「新建 / 重复跳过 / 会失败」三个数。
- [ ] AC-36.2 字段映射：正面与释义为必填映射，发音、例句、构词分析、笔记、标签、卡组名可选；能按表头自动匹配，匹配不到的在预览页手动选列。
- [ ] AC-36.3 导入完成后给出：成功 N 条、重复跳过 M 条、失败 K 条；失败逐条给**行号 + 原值片段 + 原因**（如「第 55 行：缺少释义」）。
- [ ] AC-36.4 1000 行文件能导入成功，且服务端峰值堆内存不随行数线性增长（验收：1000 行与 10000 行各跑一次，峰值增长 ≤50%）。
- [ ] AC-36.5 行内带卡组名时自动匹配同名卡组视图，不存在则创建；若已达 AC-35.4 的上限，**导入继续**，该批不打视图并明确提示。
- [ ] AC-36.6 导入时可选一个来源标记（如「Unit 5 生词」），之后能按该来源筛选与组卷复习。
- [ ] AC-36.7 文件编码兼容 UTF-8 与带 BOM 的 UTF-8；其他编码给出明确报错，不静默乱码。

### US-37 教师维护词集

- [ ] AC-37.1 教师侧有一级导航入口，进「词集」；可创建（名称必填、说明可选）、编辑、删除、调整词条顺序。
- [ ] AC-37.2 词集可复用：同一条词集能反复布置，不需要复制出新词集。
- [ ] AC-37.3 词条顺序即学生首次预习时的呈现顺序。
- [ ] AC-37.4 删除词集不影响已发出的布置（布置是快照），也不影响学生已领的词。

### US-38 教师把词集发给班级

- [ ] AC-38.1 一次发词 = 选词集 + 选一个或多个**自己带的班** + 可选截止时间 + 可选说明。
- [ ] AC-38.2 发送时对词集内容做**快照**；之后修改词集会提示「已发出的 N 次布置不受影响」，学生端内容不变。
- [ ] AC-38.3 同一词集对同一班重复发：学生已领的词不重复入库，只追加来源并更新截止时间。
- [ ] AC-38.4 发给不带的班返回 404（不泄露班级是否存在）；未登录返回 401。
- [ ] AC-38.5 学生首页出现待办「待预习：Unit 5 生词 · 3 天后截止」，点击进入该次布置的预习页；无待办时不显示该区块。

### US-39 学生领取班级生词

- [ ] AC-39.1 预习页展示词集内容（按教师设定顺序）；点「加入我的词库」后词条入库并标记来源（哪次布置、哪个班、哪位老师）。
- [ ] AC-39.2 已在库的词只追加来源标记，不新建词条、不重置进度。
- [ ] AC-39.3 过了截止时间仍可加入，列表标「已过期」；过期不影响入库。
- [ ] AC-39.4 学生退班后，已入库的词与进度保留，来源显示原班级名。

### US-40 今日复习队列

- [ ] AC-40.1 队列 = 到期时间 ≤ 当前时间 的词，按到期时间升序；可按卡组视图或来源收窄。
- [ ] AC-40.2 队列页显示三个数：今日已复习 N 张、剩余待复习 M 张、本次新卡 K 张。
- [ ] AC-40.3 每日新卡上限默认 **20**（可配置）；超出部分次日再进队列，并显示「今天的新卡已用完」。
- [ ] AC-40.4 到期卡不限量，但单次最多加载 100 张，滚动到末尾自动加载更多。
- [ ] AC-40.5 空队列有明确空态「今天没有要复习的卡」，并给「去词库加词」入口。
- [ ] AC-40.6 队列里每张卡只出现一次（与 AC-35.2 一致），即使它同时属于多个卡组视图。

### US-41 四级评分与间隔调度

- [ ] AC-41.1 复习页正面显示单词与发音；翻面（点击卡片或空格）后显示释义、例句、构词分析、个人笔记。
- [ ] AC-41.2 四个按钮「忘记 / 困难 / 良好 / 容易」，每个都直接显示各自的下次间隔（如「3 天后」）；键盘 1–4 等价。
- [ ] AC-41.3 提交评分后立即进入下一张；同时写入一条复习日志（词条、评分、时间、可选耗时）。
- [ ] AC-41.4 按 §5 的表更新该词进度（状态、到期时间、间隔、易度）；该词下次出现的时间与表一致。
- [ ] AC-41.5 调度决策来自**可替换策略**，默认 SM-2；验收判定以「默认策略」为准，换策略不改表结构。
- [ ] AC-41.6 提交失败（断网/5xx）时停留在当前卡并提示重试；不前进、不重复记日志（同一次提交带幂等标识）。

### US-42 归属、越权与隐私

- [ ] AC-42.1 学生只能看到自己的词库、卡组视图、复习记录；访问他人资源返回 404。
- [ ] AC-42.2 教师只能看到自己创建的词集与自己发出的布置。
- [ ] AC-42.3 本期不向教师返回任何学生背诵明细（接口层面不返回，不是前端隐藏）。
- [ ] AC-42.4 审计与运行日志不写词条正文、释义、例句与个人笔记（宪法第七条）。

### US-43 删除、保留与恢复

- [ ] AC-43.1 删除词条为软删除：不再出现在列表、队列、统计中；历史复习记录保留。
- [ ] AC-43.2 删除卡组视图不删词；删除布置不删学生已领的词。
- [ ] AC-43.3 已删除的词再次通过导入或布置进来时，**恢复原词条与原进度**，不新建。

### US-44 界面状态与文案

- [ ] AC-44.1 每个新页面都具备：空白态、有数据态、加载态、出错态（含重试）。
- [ ] AC-44.2 新增界面文案全部进 `web/src/locales/zh-CN.json` 与 `en.json`，键集对齐；组件内不出现中文字面量（`make check-i18n` 退出码 0）。
- [ ] AC-44.3 导航按宪法第十五条上线即用，不放占位空承诺；学生与教师各新增一个一级入口。

## 5. 调度参数（默认 SM-2 策略，本期取值）

参数集中一处、可调；调参不算改需求。表里标「源」的来自外部需求文档，标「补」的是文档没写、本项目补齐的。

| 评分 | 状态迁移 | 下次间隔 | 易度变化 |
| :--- | :--- | :--- | :--- |
| 1 忘记 | → 学习中 | **5 分钟**（源） | −0.20，下限 1.30（补；源只说「扣减」） |
| 2 困难 | → 学习中 | 旧间隔 ×1.2（源）；新词基线 10 分钟（补） | −0.15，下限 1.30（补） |
| 3 良好 | → 复习中 | max(1 天（补）, 旧间隔 × 易度（源）) | 不变（源） |
| 4 容易 | → 复习中 | max(4 天（补）, 旧间隔 × 易度 ×1.3（源）) | +0.15，上限 3.00（源：加、上限 3.0） |

- 新词初始：状态「新词」，易度 2.50（源），首次进队列当天到期。
- 毕业（补，源只说有 `GRADUATED` 状态）：连续 4 次「良好/容易」且当前间隔 ≥90 天 → 已掌握；
  已掌握的卡在间隔 ≥180 天时复查；任何一次「忘记/困难」回到「学习中」。
- 每日新卡上限 20（补，源未定义）。

## 6. 非功能需求

| 类别 | 要求 |
| :--- | :--- |
| 性能 | 今日队列接口 p95 ≤200ms（单学生 1 万词规模）；评分提交 p95 ≤150ms；1000 行导入 ≤30s |
| 并发 | 同一学生多标签页对同一张卡提交评分不双记（幂等标识）；同一词重复领取不产生重复行 |
| 隐私 | 教师不可见学生背诵明细；日志与审计不含词条正文、释义、例句、笔记 |
| 可观测 | 发词、领取、删词、批量导入写审计事件；导入失败条数进指标 |
| 国际化 | 中英双语，键集强制对齐；后端错误走消息 key |
| 模块边界 | vocab 只依赖 `shared / identity / classroom`；`paper / sitting / grading / report` 改动数为 0 |
| 软删除 | 词条、词集、布置均为软删除；删除后常规查询不可见 |
| 可维护 | 调度策略、导入解析器、来源标记为可替换边界；表前缀 `vocab_` |

## 7. 边缘情况

| 情况 | 期望行为 |
| :--- | :--- |
| 同一个词先由教师发出、后被学生自己添加 | 只有一条词条；来源追加两条；内容以教师词集为准，个人层归学生 |
| 同一个词以不同大小写/全角进库 | 规范化后视为同一条，不新建 |
| 词集已发，教师改了其中某个词 | 已发出的布置保持快照内容；界面提示后续布置才生效 |
| 学生已退班，老师再次发同一词集 | 该学生不再收到待办；已入库的词与进度保留 |
| 卡组视图条件命中 0 个词 | 视图保留，显示空态，不自动删除 |
| 卡组视图达到上限时导入带卡组名 | 导入继续，该批不入视图，结果里明确列出该批 N 条未分组 |
| 导入文件只有一列 | 预览阶段就拦下，说明「至少需要正面与释义两列」，不产生半成品数据 |
| 导入行释义为空 | 该行失败并记录行号与原因，其余行继续 |
| 复习时网络中断 | 停在当前卡、提示重试；不前进、不重复记日志 |
| 同一天多次复习同一张卡（忘记后 5 分钟又来） | 允许；每次各记一条日志，进度按最后一次推进 |
| 学生时区与服务器不同 | 本期「今日」按部署时区（Asia/Shanghai）计算，发布说明中写明（见 A-3） |
| 删除词条后又从布置里领到同一个词 | 恢复原词条与原进度，不新建、不重置 |
| 教师在截止后才发词 | 允许，截止时间只用于学生端标记与待办 |
