- 特性编号：`004-vocab`

- 上游：`specs/004-vocab/source-requirements.md`（外部需求抽取）、`docs/decisions/011-vocab-requirements.md`（本期决策）、宪法第十四条（模块边界）与第十五条（UI）

## 1. 摘要

给 TeachLoop 增加一层「背单词」，主用例是**老师课前把下一节课的生词发给班级，学生提前预习**，
词进入学生的**总词汇库**并按间隔重复排复习。

与外部需求文档的关键差异（详见决策 011）：

| 议题 | 外部文档 | 本规格 | 原因 |
| :--- | :--- | :--- | :--- |
| 库的结构 | 每个用户多个卡组，卡片属于卡组 | **一个总库** + 卡组是「保存的筛选」，不拥有卡片 | 课程按学期增长，卡组当容器会爆炸；同一个词会被背多遍 |
| 进度唯一性 | 进度挂在 `(user, card)`，卡片可重复 | 进度按 `(学生, 词条)` **唯一** | 同一个词从几门课进来也只有一份进度 |
| 账号 | 注册/手机验证码/双 Token | 复用 TeachLoop 身份模块 | 用户 2026-10-23 确认 |
| 老师发词 | 无 | **第一期就做**（词集 × 班级 × 截止时间，发送时快照） | 主用例 |
| 算法 | SM-2 公式 | 可替换策略，默认 SM-2；参数见 §5 | 用户 2026-10-23 选择 |

本期做：卡片 / 词库 / 卡组视图 / 批量导入 / 教师词集 / 发词给班级 / 今日复习 / 两档评分调度。

## 2. 角色

| 角色 | 能做 | 不能做 |
| :--- | :--- | :--- |
| **学生** | 维护自己的词库（加词、导入、改标签）、建少量卡组视图、领取班级生词、按队列复习并评分 | 看他人词库；改教师词集的词条内容；看未发给自己的词集 |
| **教师** | 建/改/删自己的词集、把词集发给自己带的班（可设截止时间）、重复发同一词集 | 看学生词库与背诵明细（本期）；发给自己不带的班 |
| **管理员** | 沿用现有能力（不新增） | — |

账号、登录、资料补全、CSRF、限流全部复用现有身份模块（宪法第十四条允许 vocab 依赖 `shared / identity / classroom`）。

## 3. 用户故事与验收标准

### US-46 学生建立与维护自己的词库

> 学生要能把词加进来，并且**一个词只有一条**，不管它从哪儿来。

- [ ] AC-46.1 学生侧有一级导航入口，进「我的词库」；空库显示空态并给两个入口（手动加词、批量导入）。**空态时「班级发来的生词」横幅仍然显示**——新用户第一眼靠它找到内容入口。
- [ ] AC-46.2 手动加词表单：**正面必填（≤64 字符）**；释义、发音、例句（可多条）、构词分析、标签（多个）都可选——不填的由异步内容生成补齐；保存后立即出现在列表首行，无需刷新。**个人笔记 V1 不做**（见 §9）。
- [ ] AC-46.3 添加一个规范化后已存在的词（规范化见 FR-093）时不新建词条：提示「已在词库（来源：X）」，仅更新个人层（标签/收藏）。
- [ ] AC-46.4 列表支持：搜索（正面/释义）、按来源筛选（全部 / 某次布置 / 某次导入 / 自己添加）、按卡组视图筛选、分页（20/50/100）。**搜索框固定在列表上方、滚动时始终可见（sticky）**，并承担两个语义：
  - 输入时：实时筛选「我的词库」；
  - 按 **Enter**：打开该词的详情页（在库的词进自己的详情；**不在库的词直接查本地词表**并进详情，详情页给「加入词库」）。
  **默认排序 = 下次复习时间升序**（新词与到期词自然排在最前），不是字母序；点表头可按任意列排序。
- [ ] AC-46.5 学生可改自己创建词条的全部字段；来自教师词集的词条**内容只读**（正面、发音、释义、例句、构词），只可编辑个人层，并在界面上标注来源。

### US-47 卡组 = 保存的筛选条件，不是容器

> 防止「一学期几十个卡组」；卡组只回答「我要看哪一部分」。

- [ ] AC-47.1 学生可创建卡组视图，条件为以下各项的任意组合：来源、标签、学习状态（新词 / 学习中 / 复习中 / 已掌握）；保存后在词库侧栏出现。
- [ ] AC-47.2 一张卡同时命中多个卡组视图时，「今日复习」里**只出现一次**。
- [ ] AC-47.3 删除卡组视图不删除任何词条或进度；重建同条件视图后，数据与删除前一致。
- [ ] AC-47.4 单学生卡组视图数量上限默认 **20**，由 `teachloop.vocab.decks.max-per-student` 配置；达到上限时创建按钮禁用并说明原因，已有视图不受影响。
- [ ] AC-47.5 界面上不存在「把卡片移入/移出卡组」的操作；只有「编辑筛选条件」。

> **2026-10-25 变更：本故事暂缓实现。** 学生分组改用 **US-69 学生词单**（只引用词条的容器）。理由：用户要的核心动作是「手动把查到的这一个词加进某份 list」，AC-47.5 恰好禁止这个动作；`vocab_decks` 表与 `deckId` 查询参数保留但不开接口与页面。AC-47.x 原文不删，将来若恢复「保存的筛选条件」仍按此验收。决策见 `docs/decisions/020-vocab-word-lists.md`。

### US-48 批量导入单词

- [ ] AC-48.1 支持 `.csv` / `.md` / `.txt`（**三种必须支持**），`.xlsx` 为可选；单文件 ≤20MB；提交前先出**预览**：总行数、前 20 条、预计「新建 / 重复跳过 / 会失败」三个数。**纯词表（只有单词、没有释义）可以导**，不当作失败。
- [ ] AC-48.2 字段映射：有表头时才做列映射（正面必填映射，释义可选映射）；发音、例句、构词分析、标签、卡组名可选；匹配不到时在预览页手动选列。**无表头的纯词表**跳过映射，直接按 FR-108 的切分规则解析。**「批量导入文件」与「粘贴文本加词」是同一个动作的两种输入**：都只做「把词加进词表」，提交后走同一条异步生成管线，结果一致。
- [ ] AC-48.3 **导入/加词只负责入库，内容按需生成**：提交后立刻能看到这些词（词形、来源、语言）；释义/例句/构词/词族在**学生开始复习或打开词详情时**按窗口生成（2026-10-24 起，见 AC-48.13），导入不再全量预生成；**已存在的词不重复生成**；未准备、生成中、生成成功、生成失败四种状态在列表可见；失败可单条或批量重试。
- [ ] AC-48.4 进入复习时只为**前 N 个词**准备内容（默认 N=20，`teachloop.vocab.review.prepare-first`）：这批准好之前页面显示「数据准备中…（已准备 x/N）」，**等满 N 个词才出卡**（2026-10-24 用户要求；常见词通常已提前生成，现场请求很少）；生成失败或等待超过 60 秒时给出可见状态、重试与「先开始」兜底。准备任务排在后台任务之前；超过 24 小时仍未完成的任务标「内容缺失」。
- [ ] AC-48.13 **懒加载窗口**：复习内容按 20 → 100 → 200 → 400 → 800… 逐级放大，学生背到窗口末尾前再准备下一段；窗口上限 `teachloop.vocab.review.prepare-window-max`（默认 1000）。自由复习会话按 cursor 位置套用同一套窗口。导入仍可用 `teachloop.vocab.generation.on-import=true` 恢复「导入即全量生成」的旧行为。
- [x] AC-48.14 **词内容全局共享**：同一 `(language, normalized_form)` 的内容只生成一次，不同学生命中同一份；只读预生成包（pack + 内存索引 + manifest）命中不调 AI，AI 现场生成的内容写入本地 SQLite delta 并写回内存索引；用户词条只存 `content_id`，不保存内容副本。Bloom filter 在词条量级到百万级前不引入（见 decisions/017）。
- [ ] AC-48.5 **格式清洗自动执行且可追溯**：去首尾/连续空格、全角逗号分号、BOM、引号、行首序号与项目符号、混入的音标或词性标注；每类改动在预览里逐条列出「第 N 行：去掉了 X」（不静默）。
- [ ] AC-48.6 **拼写校验只提示、不自动改**：每个词标为「词表命中 / 疑似拼错（给 ≤2 个候选）/ 词表外」；疑似行可逐条「用建议」或「忽略」；顶部可「全部采用建议」，但**必须二次确认并列出将被改写的词**。
- [ ] AC-48.7 「词表外」只是提示，**不阻拦导入**；专有名词、缩写、生僻词照常入库，并在列表里保留「词表外」标记直到内容生成完成。
- [ ] AC-48.8 导入完成后给出：成功 N 条、重复跳过 M 条、失败 K 条；失败逐条给**行号 + 原值片段 + 原因**（如「第 55 行：缺少释义」）。
- [ ] AC-48.9 1000 行文件能导入成功，且服务端峰值堆内存不随行数线性增长（验收：1000 行与 10000 行各跑一次，峰值增长 ≤50%）。
- [ ] AC-48.10 行内带卡组名时自动匹配同名卡组视图，不存在则创建；若已达 AC-47.4 的上限，**导入继续**，该批不打视图并明确提示。**（2026-10-25 改：这里的「卡组」由 US-69 词单承接，见 AC-69.5；上限改按 AC-69.4 的 `lists.max-per-student`。）**
- [ ] AC-48.11 导入时可选一个来源标记（如「Unit 5 生词」），之后能按该来源筛选与组卷复习。
- [ ] AC-48.12 文件编码兼容 UTF-8 与带 BOM 的 UTF-8；其他编码给出明确报错，不静默乱码。

### US-49 教师维护词集（列表 = 表格 + 编辑页）

- [ ] AC-49.1 教师侧有一级导航入口，进「词集」；**页面是表格视图，一行一个词集**，
      列为：`名称 / 词数 / 状态（启用·停用）/ 已发给几个班 / 更新时间 / 操作`（学习语言列 2026-10-24 用户要求去掉）。
- [ ] AC-49.2 每行最左有复选框，表头有全选；选中后出现批量操作条：**启停切换 + 删除**。
      **启用/停用合并成一个切换按钮**（2026-10-24 教师要求）：选中项全部启用时按钮显示「停用」，否则显示「启用」；可逆动作不再二次确认。删除仍二次确认并显示将影响 N 个词集。
      「更新」在每行操作列，是单行动作（进入编辑页）。
- [ ] AC-49.3 点词集名称或「更新」进入 **new / update 编辑页**，单栏布局：**名称、备注、词条**（学习语言不再让教师选，2026-10-24 用户决定；V1 固定 en）；页面底部右侧是「取消 / 保存」（取消返回词集列表）。保存时**同时完成批量文本的解析与加入**（不再有「解析预览 / 加入词集」按钮），结果用页面内绿色/红色提示条显示（如「添加完成（9/9）」），不使用弹窗。**编辑页不设右侧信息栏**（2026-10-23 用户要求去掉了「这个词集的去向」卡片）。
- [ ] AC-49.4 批量加词文本域只在编辑页；列表页不出现「导入单词 / 加词」；点「保存」时解析并入库，重复词跳过、结果页内提示。
- [ ] AC-49.5 停用的词集不能再被发词，但仍能看到历史发词记录；已发出的布置不受影响。
- [ ] AC-49.6 词集可复用：同一条词集能反复布置，不需要复制出新词集。
- [ ] AC-49.7 词条顺序即学生首次预习时的呈现顺序。
- [ ] AC-49.8 删除词集不影响已发出的布置（布置是快照），也不影响学生已领的词。
- [ ] AC-49.9 词集里的「移除」只把词**移出该词集**：不删除词条、不影响学生已领的词与复习进度；编辑页要示意这一点。
- [ ] AC-49.10 词集页顶部有两个 tab：**词集**（表格）与**发词记录**；发词记录按时间倒序，每行给出词集、班级、发送时间、截止状态、领取情况，并可**复制给学生**的预习链接。
  按钮文案与提示必须说明这是**学生链接**（不是老师的预览/存档链接）：复制成功提示「发给本班学生即可（只有本班收件学生能打开）」；复制失败提示检查浏览器剪贴板权限（不再提示「复制地址栏」，因为老师此刻地址栏上是词集页）。
  老师自己打开这条链接时，接口返回 403、页面显示「这是给学生的链接」并给「返回词集」出口，不是裸的 404 报错（2026-10-24 用户反馈）。

### US-50 教师把词集发给班级

- [ ] AC-50.1 一次发词 = 选词集 + 选一个或多个**自己带的班** + 可选截止时间 + 可选说明。
  - **词集选择器是可输入搜索的下拉**（输入即过滤，候选显示词数与已发班级数）；只列启用状态的词集。
  - **班级选择器是平铺的 chip 面板**：每个班显示人数、带搜索框、顶部「全选 / 清空」，实时显示「已选 N 个班 · 预计 M 名学生」；18 个班时面板内滚动。**不按年级分组**——现有系统没有「年级」层级（2026-10-23 确认）。
  - 说明性内容（学生端会看到什么、发送后发生什么）**不占版面**，收进 ⓘ 气泡。
- [ ] AC-50.2 发送时对词集内容做**快照**；之后修改词集会提示「已发出的 N 次布置不受影响」，学生端内容不变。
- [ ] AC-50.3 同一词集对同一班重复发：学生已领的词不重复入库，只追加来源并更新截止时间。
- [ ] AC-50.4 发给不带的班返回 404（不泄露班级是否存在）；未登录返回 401。前端对非本人班级**灰显并标注「非本人班级」、不可选**，且不发起请求。
- [ ] AC-50.5 学生端第一屏出现待办横幅「待预习：Unit 5 生词 · 3 天后截止」，点击进入该次布置的预习页；无待办时不显示。**V1 的位置是词库页顶部横幅**（mock 采用），独立首页的待办区块留到有首页时再放（2026-10-23 记）。
- [ ] AC-50.6 发词后给收件学生的站内通知要写明**班级、老师、词集名与截止时间**，形如「三年二班的周杰伦老师发来一组生词『不规则动词预习』，请在 10/28 15:00 之前完成预习」；没有截止时间时改为「请在截止前预习」。**标题固定为「新的词集」**（英文 "New word set"），detail / detail_nodue 两个变体都要有自己的 title 键，缺键会让标题渲染成空（T425）。正文按学生界面语言渲染（中文/英文模板都在 `messages*.properties`），截止时间按部署时区 `teachloop.notification.due-zone`（默认 `Asia/Shanghai`）渲染；`teacher` 存 `users.display_name` 原文，**渲染时先去掉末尾自带的「老师」再套模板补称谓**，避免「周杰伦老师老师」；英文模板不加中文称谓。2026-10-24 学生反馈，T425 修订。

### US-51 学生领取班级生词

- [ ] AC-51.1 预习页展示词集内容（按教师设定顺序）；点「加入词库」后词条入库并标记来源（哪次布置、哪个班、哪位老师）。**按钮文案就是「加入词库」，不写「我的」**；「返回词库」与「加入词库」**在页头同一行，返回在左、领取在右**，词表下方不再放返回按钮（2026-10-26 用户要求：领取成功后本就跳去词库，返回只是「不想加、先走」的出口，不该要滚到词表末尾才看见）。
- [ ] AC-51.2 已在库的词只追加来源标记，不新建词条、不重置进度。
- [ ] AC-51.3 过了截止时间仍可加入，列表标「已过期」；过期不影响入库。
- [ ] AC-51.4 学生退班后，已入库的词与进度保留，来源显示原班级名。
- [ ] AC-51.5 **链接在未登录时也能落到正确位置**：学生点老师发来的预习链接但没登录，登录成功后回到那条布置的预习页（未登录期间地址留在 `?next=`，只接受站内路径，防开放重定向），不需要再自己找。2026-10-24 用户要求。
- [ ] AC-51.6 **加入后新词排在词库最上面**：点「加入词库」成功后进入词库，按「加入时间倒序」（`sort=createdAt&dir=desc`）展示，本次新入库的词在顶部；**词库里本来就有的词不因为这次领取被顶到顶部**（它们保持原 `created_at` 位置）。词库的默认排序仍是「下次复习时间升序」（AC-59.6），不因这次改动变化。2026-10-24 用户要求。

### US-52 今日复习队列

- [ ] AC-60.8 详情页**不提供撤销上一次评分**（2026-10-23 决定）；误点的官方路径是「搜索该词 → 词库行 → 暂停 → 恢复」（进度归零、日志保留）；详情页（T436 起只读）不再放暂停按钮。
- [ ] AC-60.4 详情页提供一个**小小的反馈按钮**（放在单词右上角，与收藏/暂停同区，默认低调）；提交时带上 **word id** 即可（服务端按 id 取当时的快照，不必把整份 JSON 塞进请求）。2026-10-23 修订：原「带整份 JSON」改为带 id，理由是有 id 就能查到详情。
- [ ] AC-60.5 详情页是**模板 + JSON**：同一份 HTML 模板渲染不同单词，不允许每个词一个页面文件。
- [ ] AC-60.6 **内容全局共享与预生成（2026-10-24 改）**：词内容以只读内容包（`content-<lang>-<version>.pack` + `.idx` + `manifest`）+ 内存索引为主，AI 现场生成的新内容写本地 SQLite delta；同一 `(language, normalized_form)` 只生成一次，不同学生共享；**不生成逐词 HTML**，也不再用 Bloom filter 做页面否定（词条到百万级、索引需要落盘时再议，见 decisions/017）。未命中时由 prepare 入队 AI，期间页面按 T428 显示「数据准备中」。
- [ ] AC-60.7 **词族数据本地优先**：命中本地词表（Paul Nation word family 表）时直接显示同族词与频段，按频次降序、排除当前词、最多 N 个（默认 8，可配置）；未命中的词由异步生成补上并回填，下次直接命中。命中时显示频段标签（如「BNC 第 3 千词族」），未命中时不编造频段。
- [ ] AC-60.9 **内容结构 v2（多语言）**：每条内容含 `schemaVersion`、`word`、`language`、`basicInfo{pronunciation{uk,us}, partOfSpeech[], image?}`、`meanings{zh,en}`（只产 zh/en，**不产 es**，见 decisions/018 §8）、`examples[{text, translations, partOfSpeech, usagePattern, popularity}]`、`wordFormation{analysis, parts[{text,type,meaning}], confidence?}`（可选，没把握就省略）、`memoryAids{synonyms,antonyms,mnemonic,supplement}`、`wordFamily.items[{word,partOfSpeech[],meanings}]`。**例句 1–6 条**：自然情况给 6，虚词/罕见词/单义名词 1–3 也接受，绝不硬凑；`usagePattern` 可重复但句子不重复；`popularity` 1..N 按词性常用度与用法常见度排序；页面默认显示 3 条，More 展开剩余；正文高亮目标词（见 decisions/018）。
- [ ] AC-60.10 **语言档案（per user）**：`mainLanguage`（解释语言）/ `targetLanguage`（词的语言）/ `displayOrder`，默认 zh + en（内容只产 zh/en，es 不做）；存 `vocab_language_profile`，学生在个人资料页修改；内容按 target 语言缓存、`meanings` 覆盖 zh/en，换主语言不重新生成。
- [ ] AC-60.12 **运行时按需生成（L1/L2 未命中 → AI）的调用契约与性能（2026-10-25 用户定）**：内容读取顺序 = 内存索引/只读包（L1）→ 本地 delta（L2）→ AI 实时生成；AI 只由异步生成任务触发，请求线程不阻塞（页面按 T428 显示「数据准备中」）。调用参数以 `teachloop-vocab/src/main/resources/vocab/content-prompt-v2.3.json` 为**唯一来源**（Java 运行时与 `scripts/vocab` 共用，禁止两边各写一份）：`thinking:{"type":"disabled"}`（不关会先吐 9k–24k reasoning tokens 把输出预算吃光导致正文截断）、`max_tokens 6000`、`temperature 0.2`（重试 0.1）、`response_format:{"type":"json_object"}`、单请求超时 20s、显式 User-Agent（Python urllib 默认 UA 会被 Cloudflare 拦成 `403 error 1010`，Java 侧同样显式设置）、`x-opencode-session` 每请求随机 UUID（网关路由头，缺失返回 `400 MissingSessionID`，与对话上下文无关）。**截断不算成功**：`finish_reason=length`、输出 token 顶满预算、`reasoning_tokens>200` 或正文为空，一律重试一次（温度 0.1）后置 FAILED，绝不写入内容存储。性能：批量/预取吞吐 **≤1.5 秒/词**（≥4 并发；3,000 词实跑 1.1 秒/词、6 并发）；单请求 p50 ≤7s、p95 ≤10s（实测 p50 6.1s / p90 8.7s）；成本基线 $0.00068/词（OpenCode Go `deepseek-v4.1-flash`）。生成结果写 delta 并回填内存索引，同一 `(language, normalized_form)` 之后不再调 AI（AC-60.6）。
- [ ] AC-60.11 **可配置页面模板**：词详情的 section 顺序、显隐与例句显示条数存 `vocab_ui_config`（key=`word_detail_template`），管理员接口可改，前端按配置渲染；调整顺序（如例句置顶）不需要改代码或重新部署。

### US-61 词库内自由复习（不受到期限制）

> 学生经常这样用：打开一个词集从头过一遍，会的直接标掉；或者干脆把 1000 个词全过一遍，过到第 500 个没时间了就停。

- [ ] AC-61.1 词库与词集页都有**「开始复习」入口**，范围 = **当前筛选条件命中的全部词**（不是当前页显示的那几行），不受到期时间与每日新卡上限限制；**状态为「已暂停」的词自动排除**，按钮上的数量就是排除后的可复习数。
- [ ] AC-61.2 自由复习的每张卡用同一套两档评分（认识 / 不认识）；另可点**「暂停」开关**（卡片头部收藏旁的 ⏸，快捷键 `S`）：点一下停止该词排期、**原地不跳**（游标不动、不参与 SRS），图标变 ▶、评分按钮置灰；再点 ▶ 撤销暂停、**保留进度**（区别于 AC-59.3 的「恢复 = 回到新词」），可继续评分。**「下一个」（`N` / `→`）随时可点**，跳过当前词——只推进游标，不写日志、不动排期（T436）；暂停/恢复用同一位置的开关图标（`PauseCircleOutlined` ⇄ `PlayCircleOutlined`，非红色），不再占卡片下方一个文字按钮；删除仍用垃圾桶 + 二次确认，二者语义不混。
- [ ] AC-61.3 随时可以**结束复习**：结束页显示本次看了多少、暂停多少、认识/不认识各多少；未看的词保持原状态不变。
- [ ] AC-61.4 **进度可续**：下次从同一范围再次开始时，默认从「上次停留的位置」继续，并显示「上次看到第 501 / 1000」；也可以选择从头开始。
- [ ] AC-61.5 自由复习是独立会话，不写入「今日复习」的完成数；但**「认识」按与今日复习相同的调度规则推进进度**（2026-10-23 定），「暂停复习」会改变该词状态与统计。
- [ ] AC-61.6 复习结束页有明确的下一步：返回词库 / 继续复习剩余词 / 去看今日复习。

### US-69 学生词单：自己攒一份词、按单复习

> 2026-10-25 用户提出：「我查一个生词，然后把它加到我这个 list 当中。然后我没事的时候，我就想开始复习一下。」
>
> 收藏只能充当**一份** list，不能改名、不能写描述、不能排序，也装不下「考研核心词 / 小说生词」这种并存的分组。词单只做引用：**词条一份、进度一份**，词单不复制任何排期。

- [x] AC-69.1 学生可创建 / 改名 / 删除自己的词单。一份词单有**名字（1–80 字，同一学生内不重名，大小写不敏感）**、可选**描述（≤200 字）**、排序位。词单是**只引用词条**的容器：词条仍按 `(学生, 语言, 词形)` 只有一份，学习进度仍只有一份（`vocab_progress` 主键 = 词）。同一个词出现在多份词单里，复习后**只有一份排期**，不存在「一份词单一套进度」。**排序位只保留在数据层，V1 不提供拖动排序**（顺序 = 加入顺序，2026-10-25 拍板）。
- [x] AC-69.2 一个词可同时属于多份词单；同一份词单内同一个词只挂一次（重复加入不报错、不重复计数：「加入词单」弹层里该词单行显示「已在词单」并置灰）。词单内顺序 = 加入顺序。
- [x] AC-69.3 删除词单**不删除任何词条与进度**，只删引用；删除为软删，删除后从列表消失；**确认条必须写明「不会删除词条与学习进度」**。恢复词条（AC-55）后，它仍在原来所属的词单里。**V1 不提供回收站与恢复入口**（2026-10-25 拍板）。
- [x] AC-69.4 单学生词单数量上限默认 **100**，由 `teachloop.vocab.lists.max-per-student` 配置；达到上限时创建按钮禁用并说明原因，已有词单不受影响。
- [x] AC-69.5 加入词单有三个入口：**查词页（`word-details`）**、**词库行内操作**、**导入时指定词单名**（承接原 AC-48.10 的「卡组名」，2026-10-25 起改指词单）。要加入的词若不在本人词库，**一步合并**：先入库再引用，弹层里写明「会先加入你的词库」，不再单独给「先加入词库」一步；导入时词单名不存在则自动创建，已达上限则**导入继续**、该批不入词单并明确提示。**弹层里新建的名字与已有词单重名时复用已有并选中**（不报错；直接调创建接口仍按 AC-69.1 返回 409），2026-10-25 拍板。
- [x] AC-69.6 词单详情页显示名称、描述、词数、逐词列表（顺序 = 加入顺序）；可**移出单个词**（只删引用，不动词条与进度）、可**在同一个「编辑词单信息」弹层里改名与改描述**、可删除整份词单。被移出的词仍在词库。**移出单个词不二次确认，V1 不做批量移出**；**暂停词保留在表内并加「已暂停」chip，不置灰、词单里不提供恢复入口**（恢复仍在词库页 / 今日复习，AC-59.3）；**列表页每行也直接提供「开始复习（N）」**，N 为排除暂停后的词数（2026-10-25 拍板）。
- [x] AC-69.7 词单详情页有「开始复习」：范围 = **这份词单里未被暂停的全部词**（与 AC-61.1 同一排除口径），不受到期时间与每日新卡上限限制；复用自由复习会话（同一张卡、同一两档评分），结束后回到词单详情并显示小结（承接 AC-61.3）。**保留「跳过（`N` / `→`）」**：只推进游标、不写日志、不动排期、不计入认识/不认识（与 AC-61.2 同一动作），并计入小结的「跳过」；窄条显示「本次范围：<词单名> · N 词（已排除暂停）」，按钮数量 = 排除暂停后的数。
- [x] AC-69.8 词库页可按词单筛选（多选，与来源 / 标签 / 状态 / 收藏取交集），筛选条件进 URL 可还原（承接 AC-59.x 的 URL 口径）。
- [x] AC-69.9 词单只属于创建者：访问他人词单一律 **404**（不泄露存在性）；教师与管理员都不能查看学生词单；接口不返回他人词单的数量或名称。
- [x] AC-69.10 空词单有明确空态与「去加词」入口（**0 词时列表行的「开始复习」禁用**；详情页显示空态并给「＋ 加词」）；列表与详情都有空 / 加载 / 出错 / 有数据四态，出错可重试；文案入 `vocab.lists.*` 中英同步（承接 FR-103）。
- [x] AC-69.11 入口不新增一级导航：学生一级导航仍是「我的词库 / 今日复习」两项（FR-104）；词单列表从词库页工具条进入（`/vocab/lists`），词单详情为 `/vocab/lists/:id`；工具条按钮是**纯文字「词单」，不带数量角标**（角标在侧栏是「未读」语义，2026-10-25 拍板）。

## 13. 词表数据源：本地词族表（Paul Nation）

详细实测与算法见 `docs/research/2026-10-23-vocab-wordlists-feasibility.md`。这里只列**不可协商的口径**。

### 14.1 数据与语义

| 项 | 口径 |
| :--- | :--- |
| 来源 | Paul Nation 的 BNC/COCA word family 表（用户本地目录，**原始 txt 不入库**） |
| 规模（实测） | 频段 1–30：**28,276 个词族 / 80,585 个词形**（去重 80,579）；另有专有名词 22,087 族、前缀表 50 项、学科词、缩写、法语借词 |
| 行格式 | 族首行无缩进，`族首词 + 族总频次`；成员行行首一个 Tab，`词形 + 该词形自身频次` |
| 族首数字含义 | **整个词族的总频次**（不是族首词自身频次）；族首词自身频次 = 族总频次 − 成员频次合计，为负时不显示 |
| 文件号含义 | 频段（`basewrd1` = 第 1 千词族，依此类推），用于「第 N 千词族」标签与排序 |

### 14.2 解析规则（必须全部满足，否则会出现静默错数据）

- 兼容 **LF 与 CRLF**；空行跳过。
- 以**行首是否有 Tab** 判断族首 / 成员，不靠空格数。
- 每行只取「第一个 token = 词」「最后一个 token = 频次」，中间空白忽略。
- 入库统一 **NFC + 小写 + 去首尾空格** 作为 `normalized_form`；同时保留原形用于展示。
- 另建一份**去变音符**索引（`ÉCLAT → eclat`），保证用户不打变音符也能命中。
- **不依赖文件内顺序**（源文件不是严格按字母或频次排序）。
- 重复词形按**频次高者**归属，并记录来源频段。
- 族频次低于某成员的噪声族（实测 3 个），展示时只给族频次、不给单形频次。

### 14.3 查找与回退

1. 精确查 `normalized_form`；2. 未命中查去变音符索引；3. 仍未命中 → 交给异步内容生成（FR-113），生成结果带词族并回填索引。

未命中时**不得编造频段**；页面只显示「词族待补全」。

### 14.4 展示

- 词族最多显示 **N 个（默认 8，`teachloop.vocab.word-family.max-members`）**，按成员频次降序，排除当前词。
- 命中时显示频段标签（如「BNC 第 3 千词族」）与族频次。
- 词族数据缺失不影响详情页其余内容渲染（降级为不显示该区块，不报错）。


## 14. 导入语法（含 `.md`）

样例已收进 `specs/004-vocab/fixtures/import/sample-4-formats.md`（用户的四种写法）。

### 15.1 行类型

| 行 | 处理 |
| :--- | :--- |
| 空行 | 跳过（不报错、不计数） |
| `# 标题` / `> 引用` | 当说明文字跳过，**计入「跳过行数」** |
| ```` ``` ```` 围栏 | 切换代码块状态；块内行按普通词行解析 |
| 表格行 `\| a \| b \|` | 按单元格切；**分隔行**（`---`）跳过；首个非分隔行当作表头 |
| 列表项 `- a` / `* a` / `1. a` / `1) a` | 去掉标记后按普通词行解析 |
| 普通行 | 按 FR-108 切分：逗号（中英文）、空白、分号；忽略空 token 与行尾分隔符 |

### 15.2 说明文字与「静默丢弃」

- 导入语言为 `en` 时，**含中日韩字符的行视为说明文字跳过**（样例里的「1 一行，逗号隔开」等四行即属此类）。
- 导入语言为 `zh` 时该规则反向：含**纯 ASCII 且无中文**的短行才可能是外语说明，需在预览页让用户确认。
- 任何被跳过的行都必须在预览里给出**行号 + 原文 + 跳过原因**（宪法：静默丢弃即缺陷）。

### 15.3 验收样例（已实测）

`sample-4-formats.md` 共 22 行，解析结果：**40 条 token → 去重后 10 个**，四行中文说明被跳过并在预览里列出。

| 段落 | 行数 | 解析出 |
| :--- | ---: | ---: |
| 1 一行逗号分隔 | 1 | 10 |
| 2 一行空格分隔 | 1 | 10 |
| 3 每行一个 | 10 | 10 |
| 4 多行逗号（含混排空格） | 4 | 10 |
| 说明文字 | 4 | 0（跳过并报告） |

### 15.4 其他规则

- 含空格的短语（`take off`）必须用引号或 CSV 保护，否则会被空格切开；预览页要提示这一点。
- 表格导入时，首行是表头，列映射按表头名匹配（AC-48.2）。
- 同一文件里重复出现的词只入库一次，预览里显示「重复 M 条」。

## 18. 误点之后怎么补救（2026-10-23 已定）

决定：**不做撤销**，用现成的入口救——「搜索该词 → 进详情 → 暂停后再恢复」。

| 途径 | 效果 | 代价 |
| :--- | :--- | :--- |
| **搜索 → 详情 → 暂停 → 恢复** | 立刻回到「新词」，今天就能再复习 | 进度归零（间隔/易度重置），但不是删除历史日志 |
| 词库 → 详情 →「暂停」再「恢复」 | 同上，只是多一步 | 同上 |
| 等下次到期 | 什么都不用做 | 「认识」会按易度往后推，老词可能十几天后才回来 |
| 自由复习 | 立刻再练一遍 | 再评一次会继续往后推 |

补充两条容易误解的规则：

1. **「加词 / 导入」对已存在的词不做任何事**：命中去重后只提示「已在词库」，不会改进度——所以它救不了误点。
2. **搜索无匹配时按 Enter 直接进详情**：这是「查任意词」的入口，不在库的词在这里可以「加入词库」；在库的词在这里可以「暂停」后再「恢复」。


## 19. 收藏 / 暂停 / 删除三个动作的分工（2026-10-23 定）

学生侧同时对「一个词」有三种动作，含义必须分得开：

| 动作 | 在哪 | 效果 | 可逆 |
| :--- | :--- | :--- | :--- |
| **收藏（favorite）** | 词库行、详情页 | 纯标记，不影响词库与排期；**筛选里新增「已收藏」条件**，复习范围也可只看收藏 | 随时取消 |
| **暂停复习** | 词库行、详情页 | 不再安排复习；词仍在库、可搜索；状态「已暂停」 | 「恢复」后回到新词 |
| **删除** | **只在词库页**（行内/批量） | 软删除：列表、搜索、队列、统计全部看不到；历史日志保留 | 再次导入/被布置时按 AC-55.3 恢复 |

三条刻意不重叠：收藏不改学习状态；暂停不删词；删除不出现在详情页（避免在「看一个词」的页面里做不可逆操作）。


## 20. 导入时的清洗与拼写校验（2026-10-23 定）

| 层 | 做不做 | 规则 |
| :--- | :--- | :--- |
| **格式清洗** | **自动** | 去空格/全角标点/BOM/引号/行首序号/混入的音标与词性；每类改动逐条报告 |
| **拼写校验** | **只提示** | 用本地 80,579 个词形做三态判定：命中 / 疑似拼错（编辑距离 ≤2，给 ≤2 候选）/ 词表外 |
| **自动纠错** | **不做** | 专有名词、缩写、新词、生僻词都可能"不在词表"，静默改词是数据事故 |
| **批量采纳** | 做，但要确认 | 顶部「全部采用建议」必须二次确认，并列出将被改写的词 |

判断依据：词表外 ≠ 错误（`zyzzyva`、`ICBM`、`Polynesia` 都合法）；疑似拼错 ≈ 未命中但有编辑距离 ≤2 的候选。
