## 1. 摘要

把「个人自学」和「班级教学」从**两套落地规则**改成**一个落地页 + 数据差异**：

1. 所有学生登录后进同一个「今日」页，页面按「今天要做什么」排卡片；有班多出作业/考试，无班多出加入班级与词单。
2. 背单词从侧栏的三个一级项收成一个一级项，进去后用页内 Tab（今日复习 / 我的词库 / 我的词单），默认落今日复习。
3. 资料补全从「未填手机号一律 403」改成「首次登录收集一次、可跳过、之后顶部提示」，老师侧仍然强制。
4. 班级表预留收费字段，但第一期不做支付。

| 议题 | 现在 | 本次之后 |
| :--- | :--- | :--- |
| 学生落地页 | 一律 `StudentHomePage`（作业列表），无班时是空页 | 统一「今日」页，无班也有可做的事 |
| 背单词入口 | 侧栏 3 项：我的词库 / 我的词单 / 今日复习 | 侧栏 1 项「背单词」+ 页内 3 Tab |
| 入班 | `POST /api/classes/join`，入口在 `/classes` | 入口也出现在今日页右栏，接口不变 |
| 资料补全 | `ProfileCompletionFilter` 硬 403，除 `/profile` 外全拦 | 可跳过；老师建班/发词仍强制 |
| 班级收费 | 无字段 | 三列预留（`FREE/0/CNY`），无支付 |
| 「今天」的日界 | 硬编码 `Asia/Shanghai`（`ReviewQueueEndpoint:43`、`QuizEndpoint:51`） | 用户可见的按天口径跟随学生时区；后台任务保持产品时区 |

## 2. 角色

| 角色 | 本次变化 |
| :--- | :--- |
| **学生（未入班）** | 今日页 = 复习 + 词单 + 加入班级入口；不再看到空作业页 |
| **学生（已入班）** | 今日页 = 复习 + 待交作业 + 考试 + 班级；仍是同一路由 |
| **教师** | 页面不变；资料未补全时建班/发词仍被拦 |
| **管理员** | 不变（无班级、无学生卡片） |

## 3. 用户故事与验收标准

### US-90 学生登录后落到统一的「今日」页

作为学生，我登录后想知道「今天要做什么」，而不是先判断自己属于哪个班。

- [ ] AC-90.1 登录后访问 `/`，渲染「今日」页；页头包含当天日期（格式 `M 月 D 日 周X`）与身份副标题（有班：`班名 · 连续天数`；无班：`个人学习`）。
- [ ] AC-90.2 存在待交作业时，作业卡按截止时间升序，最多显示 3 条，每条显示所属班名；逾期条的截止标签为红色；点「查看全部」在**页内展开**全部条目，不跳转新路由。
- [ ] AC-90.3 没有待交作业时，作业卡保留并显示「没有要交的作业。」；不得整卡消失（否则学生无法区分「没有作业」和「加载失败」）。
- [ ] AC-90.4 未来 7 天没有考试时，考试卡整卡不出现；有考试时最多显示 2 条，按开始时间升序，标签写「N 天后」。
- [ ] AC-90.5 未加入任何班级时，今日页不出现作业卡与考试卡；出现「有邀请码？」卡与「我的词单」卡。
- [ ] AC-90.6 平板：在 834×1194 与 1024×1366 两档视口下 `document.documentElement.scrollWidth <= innerWidth + 2`，且「开始复习」按钮在首屏可见（`getBoundingClientRect().bottom <= innerHeight`）。
- [ ] AC-90.7 今日页首次加载只发起 `GET /api/student/today` 与 `GET /api/auth/me` 两次请求；不得对每个 offering 单独请求（禁止 N+1）。
- [ ] AC-90.8 今日页不出现「我的班级」概览卡；班级信息只作为作业/考试条目的班名标签出现；班级入口保留在侧栏「班级」一项，多班学生不需要在今日页选择班级。

### US-91 背单词从三个一级菜单收成一个模块

作为学生，我不想在侧栏里同时看到词库、词单、复习三项；它们是一件事的三个页面。

- [ ] AC-91.1 侧栏只出现一项「背单词」；「我的词库」「我的词单」「今日复习」不再是一级项。
- [ ] AC-91.2 进入「背单词」默认落到今日复习；三个 Tab 的地址分别为 `/vocab/review`、`/vocab/library`、`/vocab/lists`，直接打开任一地址时对应 Tab 高亮。
- [ ] AC-91.3 今日页点「开始复习」进入 `/vocab/review`；在复习页点「开始」后进入全屏 `/vocab/review/session/:id`，该会话页不显示 Tab 与侧栏。
- [ ] AC-91.4 `teachloop.vocab.enabled=false` 时，侧栏「背单词」与三个 Tab 都不出现；直接打开 `/vocab/*` 回到落地页而不是白屏。
- [ ] AC-91.5 页内 Tab 从左到右依次为 **今日复习 / 我的词单 / 我的词库**，进入模块默认选中「今日复习」。

### US-92 未入班的学生可以用邀请码入班，且个人数据不变

作为还没报名的学生，我输入老师给的邀请码就能进班，之前背的词和进度不能丢。

- [ ] AC-92.1 未入班学生的今日页显示「有邀请码？」卡；提交有效邀请码后，同一会话内今日页出现作业卡（若该班有作业）。
- [ ] AC-92.2 入班前后 `GET /api/vocab/words` 返回的总数与到期数不变；`vocab_progress.due_at` 不因入班改写。
- [ ] AC-92.3 邀请码无效或班级已归档时，错误显示在卡片内；页面不跳转，输入框内容保留。
- [ ] AC-92.4 已入班学生的今日页不显示「有邀请码？」卡；加入其他班走 `/classes`。

### US-93 资料补全改为可跳过，老师侧仍强制

作为新用户，我可以先试用工具再补手机号；作为老师，我不能不填联系方式就去建班。

- [ ] AC-93.1 未填手机号的学生访问 `/` 与 `/vocab/*` 返回 200，不再收到 403 `PROFILE_INCOMPLETE`。
- [ ] AC-93.2 首次登录（`users.phone` 为空）先进入 `/welcome` 收集页；页面提供「以后再说」，跳过后本设备不再自动出现（记录在 `localStorage`，键名 `teachloop.profile.prompted`）。
- [ ] AC-93.3 跳过后的会话里，页面顶部显示一条可关闭的「补全手机号」提示条；点「去补全」进入 `/profile`，关闭后本会话不再出现。
- [ ] AC-93.4 教师未填手机号时，「建班」与「发词」两个动作仍返回 403 `PROFILE_INCOMPLETE`；教师浏览其他页面不受影响（不再整站 403）。

### US-94 今日页的数据来自一个聚合接口

作为前端，我不应该为了首页并发 N 个请求再拼数据。

- [ ] AC-94.1 `GET /api/student/today` 返回 `review`（`due` / `reviewedToday` / `newToday`）、`assignments`（全部待办，含 `id` / `title` / `className` / `dueAt` / `status`）、`exams`（未来 7 天）三段，字段名与 FR-207 一致。
- [ ] AC-94.2 任一段查询失败时，对应卡片显示错误态并可重试，其余卡片正常渲染；接口整体仍返回 200。
- [ ] AC-94.3 该接口对教师与管理员返回三段空数组/零值，不报错；前端不渲染学生卡片。

### US-95 班级预留收费字段（不做支付）

作为产品负责人，我要在改入班流程之前先把学校收费的结构留出来，避免第二期重写表。

- [ ] AC-95.1 迁移执行后 `classes` 表存在 `pay_mode`（默认 `FREE`）、`price_cents`（默认 0）、`currency`（默认 `CNY`）；现存班级全部为 `FREE/0/CNY`。
- [ ] AC-95.2 建班接口不传价格字段时行为与今天一致；传 `pay_mode != FREE` 返回 400（第一期不支持创建付费班）。
- [ ] AC-95.3 入班接口遇到 `pay_mode != FREE` 的班级返回 409，提示「付费班级暂未开放」。
- [ ] AC-95.4 前端不出现价格输入与付款入口；`/classes` 的文案与布局不变。

### US-99 「今天」的日界跟随学生所在时区

作为在洛杉矶的使用者，我晚上 11 点背的卡应该算「今天」，而不是被北京的日界切到明天；同时我在国内的测试用户也要看到他们自己的「今天」。

- [ ] AC-99.1 时区解析优先级为 `X-Timezone` 请求头 > `users.timezone` > 产品默认 `Asia/Shanghai`；头缺失或用户未设置时回落到产品时区，不报错。
- [ ] AC-99.2 传入非法时区（如 `Mars/Base`、空串、超长串）时请求仍返回 200，按回落链取值；服务端日志记一条 warning，不抛 500。
- [ ] AC-99.3 北京时间 2026-11-01 00:01 与洛杉矶时间 2026-10-31 09:01 是同一时刻：两位学生调用 `GET /api/vocab/review/queue`，`todayReviewed` 分别按各自时区的当日 0 点起算，互不影响。
- [ ] AC-99.4 夏令时切换日（`America/Los_Angeles` 2027-03-14 与 2027-11-07）日界仍为当地 00:00；当天 `todayReviewed` 不重复计数、不漏计，每日新卡上限只重置一次。
- [ ] AC-99.5 学生时区 ≠ 产品时区时，今日页显示一行说明，格式为「新的一天按<城市名>时间 0 点开始（UTC±偏移）」（例：`新的一天按洛杉矶时间 0 点开始（UTC-7）`）；城市名取 `ProfilePage.tsx` 那 11 个常用时区的映射，未命中回落 `Intl` 长名称；**偏移按渲染时刻现算**，夏令时切换后自动变化（`America/Los_Angeles` 2026-10-30 显示 `UTC-7`、2026-11-02 显示 `UTC-8`），偏移为 0 时省略括号；时区相同时不显示。

## 5. 界面与交互

原型：[`docs/mock/self-study-2026-10-30/index.html`](../../docs/mock/self-study-2026-10-30/index.html)（单文件，双击可点；三组开关 + 8 条深链）。

- **今日页布局**：单列，最宽 880px；卡片顺序为 今日复习 → 待交作业 → 即将开始 → （无班时）我的词单 → （无班时）有邀请码？ → 学习记录（第二期，先不做）。
- **今日复习卡**：大数字为待复习张数，副行为「今天已复习 X / 新词 Y / 上限 Z」，主按钮「开始复习」。
- **背单词模块**：页内 Tab 顺序为 **今日复习 / 我的词单 / 我的词库**（2026-10-30 调整：先「要背的」后「管理的」）；今日复习 Tab 内只有张数与开始按钮，真正复习全屏。
- **三档宽度（2026-10-30 定）**：列表页（我的词库 / 我的词单）走满壳层内容区（现有 `.app-main` 的 `max-width:1240px`）；今日页与今日复习准备页收敛到 **880px**；复习会话（`free-review`）**全屏无侧栏**，卡片本体按现有 `review-card-column` 的 **720px** 上限居中，评分按钮在卡片下方。
  宽度不靠感觉：满屏卡片会让单行太长（一行超过 80 字符扫读掉行）、而词库表格被压到 720 会让「释义」列折行。
- **空态**：无词 → 「先加第一批词」+ 两个动作（加词 / 导入词表）；无值日 → 作业卡一句「没有要交的作业。」。
  **注**：`013-word-books` 落地后会再加第三块「从词书开始」，011 不依赖它——两者各自可上线。
- **错误态**：每张卡独立错误 + 重试，不整页报错。
- 术语按 `docs/process/glossary.md`：`today-review` 指 `/vocab/review`，`free-review` 指 `/vocab/review/session/:id`；不要用「复习卡」指这两者。

平板实测（原型阶段已完成，9 个组合）：834×1194、1024×1366、1440×1000 × 今日/词库/空态，`scrollWidth == innerWidth`、首屏外按钮数 0。数据见 mock 的 README。

## 7. 数据与接口

### 7.1 新接口

```http
GET /api/student/today
```

```json
{
  "review": { "due": 24, "reviewedToday": 8, "newToday": 10, "newLimit": 20 },
  "assignments": [
    { "id": "uuid", "title": "Unit 5 阅读理解（一）", "className": "初二（3）班",
      "dueAt": "2026-10-30T18:00:00Z", "status": "todo" }
  ],
  "exams": [
    { "id": "uuid", "title": "期中英语听说", "className": "初二（3）班",
      "startsAt": "2026-11-02T09:00:00Z" }
  ]
}
```

- `status` 今日页只返回 **两态**：`todo`（未交 / 被拒收）与 `submitted`（已交）。
  三态里的 `published` 需要 grading 模块的逐份发布状态（`ExamSessionEndpoint.scoresVisible` 走 `ReviewFeedback` 端口），
  今日卡只回答「要不要去交」，不需要它；完整三态仍由作业列表页提供。
  （2026-10-30 修订：原写「沿用三态」，在 Plan §4.1 定查询形状时发现会引入逐份端口调用。）
- 教师/管理员调用返回三段空值。
- 编排位置：`teachloop-app` 的 `StudentTodayEndpoint`，只做权限与拼装；片段查询由属主模块提供（`vocab` 给复习切片、`sitting` 给作业与考试、`classroom` 给进行中班级）。app 内不得出现业务表 SQL。
- 请求头：前端每次请求带 `X-Timezone: <IANA>`（`Intl.DateTimeFormat().resolvedOptions().timeZone`），服务端按 FR-226 解析。

### 7.2 表变更

```sql
-- classes 增加三列，全部带默认值，可在有数据的库上直接执行
pay_mode     text    not null default 'FREE'
price_cents  integer not null default 0
currency     text    not null default 'CNY'
```

### 7.3 行为语义变化

`ProfileCompletionFilter` 现在对除 `/api/auth/me` `/api/auth/logout` `/api/profile` 外的所有请求返回 403。改为：

- 普通读取请求放行，`/api/auth/me` 增加 `profileIncomplete: true`；
- 教师写操作（`POST /api/classes`、`POST /api/vocab/assignments`）在端点内校验，缺失仍返回 403 `PROFILE_INCOMPLETE`；
